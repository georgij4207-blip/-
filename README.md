# Стенд персонажа (Three.js)

Браузерный стенд для просмотра персонажа на планшете: светлый фон, сетка пола,
мультяшный рендер (`MeshToonMaterial` + толстый чёрный контур). В центре —
мультяшный койот в духе анимации 50-х: крупная голова, тощее тело, длинные
руки с четырёхпалыми кистями (ноги — следующим шагом).

## Управление

| Жест / кнопка | Действие |
| --- | --- |
| Один палец | вращение камеры на 360° вокруг персонажа |
| Щипок двумя пальцами | зум |
| Анфас · ¾ · Профиль · ¾ сзади · Спина | плавный перелёт камеры в ракурс (0°, 45°, 90°, 135°, 180°) |

Персонаж смотрит в +Z, поэтому «Анфас» — камера прямо перед ним.

Справа сверху — сворачиваемые панели позы. В каждой выбирается сторона
(обе / левая / правая — сторона самого койота, то есть «левая» справа, если
смотреть анфас), а «Сброс» возвращает позу по умолчанию. Пока панель открыта,
кадр сдвигается, чтобы она не закрывала персонажа.

- **«Руки»** — плечо (подъём вперёд/назад, отведение в сторону, поворот),
  локоть, кисть, сжатие пальцев и большой палец.
- **«Уши»** — наклон (назад/вперёд), развал (внутрь/наружу), поворот раковины
  и изгиб.

## Запуск

```bash
npm install
npm run dev      # сервер доступен и в локальной сети (--host)
```

Vite выведет адрес вида `http://192.168.x.x:5173` — откройте его на планшете,
подключённом к той же Wi-Fi сети.

Сборка статических файлов (папка `dist/`, можно залить на любой хостинг,
например GitHub Pages):

```bash
npm run build
npm run preview
```

## Как устроено

- `src/main.js` — сцена, свет, пол, управление и ракурсы.
- `src/toon.js` — материалы: `toonMaterial(color)` (`MeshToonMaterial` со
  ступенчатой `gradientMap` из трёх тонов), `twoToneMaterial(...)` (два цвета
  с чёткой волнистой границей — светлая морда и подбородок), `flatMaterial`
  для бликов.
- `src/coyote/coyote.js` — сборка персонажа. Иерархия шарниров:
  `coyote → hips (таз, место под ноги) → torso` и
  `hips → neckPivot (основание шеи) → headPivot (верх шеи) → coyoteHead`.
  Повороты `neckPivot` и `headPivot` в покое нулевые — поза покоя зашита в
  дочерние объекты, анимировать можно, крутя шарниры от нуля. Ссылки на
  шарниры — в `coyote.userData.parts`, на уши — в `coyote.userData.ears`.
- `src/coyote/arms.js` — руки. Каждая часть — отдельный сустав-группа:
  `shoulder → elbow → wrist → hand`; в кисти ладонь, три пальца и
  противопоставленный большой палец, у каждого пальца по два сустава
  (`base → mid`). Точка `grip` перед ладонью — куда вешать предметы
  (`arm.userData.joints.grip.add(предмет)`). Позу задаёт
  `applyArmPose(arm, { raise, spread, twist, elbow, wrist, curl, thumb })`.
- `src/coyote/body.js` — торс (тело вращения с выпяченной грудью, узкой
  талией и S-образной спиной) и шея. Светлое пузо и горло — режим `wedge`
  у `twoToneMaterial`: светлый передний сектор вокруг оси.
- `src/coyote/head.js` — голова койота из примитивов. Все детали — отдельные
  именованные объекты, чтобы потом их анимировать: `skull`, `snout` → `nose`,
  `eyeL`/`eyeR` (внутри `white` и группа `look` со зрачком и бликом — её можно
  вращать для взгляда), `browL`/`browR`, пучки шерсти `crest`, `nape`,
  `cheekL`/`cheekR`. Палитра — `COYOTE_COLORS`.
- `src/coyote/ears.js` — уши. Каждое ухо (`earL`/`earR`) — крепление в точке
  у основания, внутри шарнир `pivot` (наклон, развал, поворот) и две
  `SkinnedMesh` (шерсть и розовая внутренняя часть) на общей цепочке костей
  `root → mid → tip`, поэтому ухо гнётся плавно. Позу задаёт
  `applyEarPose(ear, { tilt, splay, twist, bend })` (радианы); на кости `mid`
  и `tip` позже можно повесить пружинное запаздывание.
- `src/ui/posePanel.js` — общая панель ползунков позы (руки, уши).
- Контур: `OutlineEffect` (метод inverted hull), толщина — константа
  `OUTLINE_THICKNESS`. Для пола и тени контур отключён через
  `material.userData.outlineParameters = { visible: false }`.
- Сетка пола нарисована текстурой на плоскости (линии `GridHelper` на части
  мобильных GPU пропадают), под персонажем — мягкая пятно-тень.
