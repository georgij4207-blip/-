# Схема подключения щитка

Щит управления Salda RIS 400P на плате KinCony KC868-A8. Номиналы и позиции —
`docs/bom.md`. Подробности узлов: ключ SSR — `ssr_driver.md`, блокировка скоростей —
`fan_wiring.md`, датчики — `ntc_inputs.md`.

> **Названия клемм платы** (12V/GND, K1…K8 COM/NO/NC, X1…X8, GND входов, P19, порты
> TEM/HUMI) взяты из описания платы. Перед монтажом сверить с шелкографией своей
> платы. Распиновку портов TEM/HUMI (где DATA, где GND, есть ли 3,3 В) — прозвонить.
> **Сеть 230 В, работа под напряжением запрещена.** Монтаж силовой части — электрик с допуском.

## 1. Общая структура

```
                       ┌──────────────────────── ЩИТ ────────────────────────────────┐
 Сеть 230 В ──► XT1 ──►│ QF1 дифавтомат 16 А 30 мА ──► шины L / N, шина PE           │
                       │   ├─ QF2 10 А ── T100 ── T50 ── SSR1 ─────────────► XT4 ТЭН  │
                       │   ├─ QF3 6 А  ── (T прд.) ───── SSR2 ─────────────► XT5 преднагрев
                       │   ├─ QF4 2 А  ── цепочка K3→K2→K1 ────────────────► XT2 мотор притока
                       │   ├─ QF5 2 А  ── цепочка K6→K5→K4 ────────────────► XT3 мотор вытяжки
                       │   └─ QF6 2 А  ─┬─ БП 12 В ── плата KC868-A8, модуль ключей
                       │                └─ K7 ────────────────────────────► XT6 заслонка
                       │  Плата ◄── XT7 датчики NTC, XT8 входы, реле давления         │
                       │  ADS1115 + делители, модуль ключей SSR, реле KL1 (230 В) → X1│
                       └─────────────────────────────────────────────────────────────┘
```

Термостаты ТЭНа стоят **в установке** (у ТЭНа), а провода от них заводятся в щит,
и в цепи стоят **до SSR**. Так термостат разрывает питание ТЭНа независимо от SSR
(даже если SSR пробит), а интерфейсное реле KL1 (катушка 230 В) видит его срабатывание.

## 2. Клеммник щита XT (внешние подключения)

Все внешние провода — только через клеммник щита, не напрямую на плату.

| | 12 | N | |

перемычки = авария (так и задумано: обрыв провода = авария).

## 3. Силовая часть 230 В

```
XT1.1 L ──► QF1 (1P+N, 16 А, C, 30 мА, тип A) ──► шина L
XT1.2 N ──► QF1 N ──────────────────────────────► шина N
XT1.3 PE ───────────────────────────────────────► шина PE (корпус щита, DIN-рейка)

шина L ──► QF2 10 А C ──► XT4.14 ──[T100 в установке]── XT4.15 ──[T50]── XT4.16 ──► SSR1 клемма 1
                                                                       SSR1 клемма 2 ──► XT4.17 ──► ТЭН ──► XT4.18 ──► шина N
                         реле KL1 (катушка ~230 В): A1 = XT4.15 (после T100), A2 = шина N; контакт NO → X1/GND платы

шина L ──► QF3 6 А C ──► SSR2 клемма 1;  SSR2 клемма 2 ──► XT5.20 ──► преднагреватель ──► XT5.21 ──► шина N

шина L ──► QF4 2 А C ──► K3.COM … цепочка K3→K2→K1 … ──► XT2.4/5/6;  XT2.7 ──► шина N
шина L ──► QF5 2 А C ──► K6.COM … цепочка K6→K5→K4 … ──► XT3.9/10/11; XT3.12 ──► шина N

шина L ──► QF6 2 А C ──┬──► БП 12 В: L
                       └──► K7.COM;  K7.NO ──► XT6.23 ──► привод заслонки ──► XT6.24 ──► шина N
шина N ────────────────────► БП 12 В: N
```

- **SSR**: у типовых SSR-25DA клеммы 1–2 — нагрузка ~230 В, 3 (+) и 4 (−) — управление
  3–32 В DC. Сверить с маркировкой своего SSR. Каждый SSR — на радиатор с термопастой.
- Если у термостатов нет отдельных выводов +50 °C / +100 °C (один общий провод через
  оба), XT4.15–16 — перемычка, а катушку KL1 подключить к XT4.16: тогда X1 покажет срабатывание
  любого из них (ручной сброс у +100 °C останется аппаратным).
- KL1 обесточен и при выключенном QF2: отключение автомата ТЭНа прошивка покажет как
  «Сработал аварийный термостат ТЭНа» (это безопасная сторона: нагрев не нужен — он и не включится).
- Конденсаторы моторов остаются в установке, по заводской схеме мотора.

### Цепочка блокировки скоростей (реле SPDT платы)

```
QF4 ─► K3.COM;  K3.NO ─► XT2.6 (скор. 3);  K3.NC ─► K2.COM
                K2.NO ─► XT2.5 (скор. 2);  K2.NC ─► K1.COM
                K1.NO ─► XT2.4 (скор. 1);  K1.NC — не подключать

QF5 ─► K6.COM;  K6.NO ─► XT3.11 (скор. 3); K6.NC ─► K5.COM
                K5.NO ─► XT3.10 (скор. 2); K5.NC ─► K4.COM
                K4.NO ─► XT3.9  (скор. 1); K4.NC — не подключать
```

Какой отвод мотора — какая скорость, определить прозвонкой (`docs/site_survey.md`).
Перемычки между реле — провод 0,75 мм² с наконечниками НШВИ.

## 4. Низковольтная часть 12 В / 3,3 В

### Питание

```
БП 12 В: +V ──► плата «12V»
             ──► модуль ключей J2.1 (+12 В)
         −V ──► плата «GND»
             ──► модуль ключей J2.2 (GND)
```

Минус БП — общий для платы, модуля ключей, ADS1115. PE на минус 12 В не подключать.

### Разъём P19 платы (I2C и 3,3 В)

| P19 | → ADS1115 (0x48) | → OLED SSD1306 (0x3C) | → SCD41 (0x62) | → модуль ключей | → делители |
|---|---|---|---|---|---|
| 3V | VDD | VCC | VDD | J1.1 (+3V3, аноды оптронов U1, U2) | верх делителей 22 кОм и 1 кОм на A3 |
| GND | GND, ADDR | GND | GND | J1.2 | |
| SDA | SDA | SDA | SDA | | |
| SCL | SCL | SCL | SCL | | |

OLED — на дверце или лицевой панели щита (шлейф ≤ 30 см). SCD41 — в канале вытяжки у щита,
провод I2C ≤ 1 м (`display_co2.md`).

### ADS1115 и датчики (плата делителей рядом с ADS1115)

```
+3V3 ──[22k 1%]──┬── A0 ── XT7.30 ── NTC t_extract ── XT7.31 ── GND
                 └─[100n]─ GND
+3V3 ──[22k 1%]──┬── A1 ── XT7.28 ── NTC t_exhaust ── XT7.29 ── GND
                 └─[100n]─ GND
+3V3 ──[22k 1%]──┬── A2 ── XT7.26 ── NTC t_outdoor ── XT7.27 ── GND
                 └─[100n]─ GND
+3V3 ──[1k 1%]───┬── A3   (опорное 3,3 В, ратиометрия)
                 └─[100n]─ GND

Порт TEM/HUMI 3 (GPIO36): DATA ── XT7.32 ── NTC t_supply ── XT7.33 ── GND порта
   (подтяжка 4,7 кОм к 3,3 В уже на плате — свой делитель не нужен)
Порт TEM/HUMI 4 (GPIO39): резерв.
```

Экран кабелей датчиков — на GND с одной стороны (в щите).

### Модуль ключей SSR (самодельный, схема — `ssr_driver.md`)

| Разъём модуля | Контакт | Куда |
|---|---|---|
| J1 (от платы) | 1 +3V3 | P19 «3V» |
| | 2 GND | P19 «GND» |
| | 3 CH1 | порт TEM/HUMI 1, DATA (GPIO14) — ТЭН |
| | 4 CH2 | порт TEM/HUMI 2, DATA (GPIO13) — преднагреватель |
| J2 (питание) | 1 +12 В | БП +V |
| | 2 GND | БП −V |
| J3 (реле давления) | 1 +12 В через F1 0,5 А | XT8.42 → ДР COM |
| | 2 +12V_FLOW | XT8.43 ← ДР NO |
| J4 (SSR) | 1 SSR1 «+» (+12V_FLOW) | SSR1 клемма 3 |
| | 2 SSR1 «−» (сток Q1) | SSR1 клемма 4 |
| | 3 SSR2 «+» (+12V_FLOW) | SSR2 клемма 3 |
| | 4 SSR2 «−» (сток Q2) | SSR2 клемма 4 |
| J5 (вход X7) | 1 коллектор U3 | плата X7 |
| | 2 эмиттер U3 | плата GND входов |

### Дискретные входы платы X1–X8

Вход активен при замыкании на GND платы. Внешний контакт — между клеммой Xn и GND.

| Вход | Что подключено | Контакт | Норма |
|---|---|---|---|
| X1 | контакт NO реле KL1 «230 В есть после термостата» (13–14 → X1 и GND) | — | замкнут (термостат цел) |
| X2 | XT8.34–35 реле фильтра притока | NC | замкнут |
| X3 | XT8.36–37 реле фильтра вытяжки | NC | замкнут |
| X4 | XT8.38–39 внешний стоп | NC | замкнут |
| X5 | резерв (термостат +50 °C отдельно, если появится) | NC | — |
| X6 | резерв (термостат преднагревателя) | NC | — |
| X7 | J5 модуля ключей (оптрон U3 — поток есть) | — | замкнут при работе притока |
| X8 | XT8.40–41 пожарная сигнализация | NC | замкнут |

### Реле платы K1–K8

| Реле | COM | NO | NC |
|---|---|---|---|
| K1 | ← K2.NC | → XT2.4 (приток, скор. 1) | — |
| K2 | ← K3.NC | → XT2.5 (приток, скор. 2) | → K1.COM |
| K3 | ← QF4 | → XT2.6 (приток, скор. 3) | → K2.COM |
| K4 | ← K5.NC | → XT3.9 (вытяжка, скор. 1) | — |
| K5 | ← K6.NC | → XT3.10 (вытяжка, скор. 2) | → K4.COM |
| K6 | ← QF5 | → XT3.11 (вытяжка, скор. 3) | → K5.COM |
| K7 | ← QF6 | → XT6.23 (привод заслонки) | — |
| K8 | → XT8.44 | → XT8.45 (замкнут = норма) | — |

## 5. Размещение в щите (рекомендация)

- DIN-рейка 1: QF1…QF6, БП 12 В.
- DIN-рейка 2: плата KC868-A8 (на DIN-держателе или стойках), модуль ключей, ADS1115 с платой делителей.
- Монтажная панель / рейка 3: SSR1, SSR2 на радиаторах (низом к вентиляционным отверстиям),
  реле KL1.
- Клеммник XT — внизу щита; силовые (XT1–XT6) и слаботочные (XT7–XT8) — разнесены,
  разделитель. Провода датчиков не вести в одном жгуте с силовыми.
- Щит не меньше 24 модулей, IP31+; SSR греются (≈ 10 Вт у ТЭНа) — оставить зазор сверху.
