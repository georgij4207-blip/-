# Ключ управления SSR (ТЭН и преднагреватель)

Каналы: порт TEM/HUMI 1 (GPIO14) → основной ТЭН, порт TEM/HUMI 2 (GPIO13) → преднагреватель.
Схемы обоих каналов одинаковые.

## Задача

На плате каждый порт TEM/HUMI устроен так: подтяжка 4,7 кОм к +3,3 В и 100 Ом
последовательно к выводу ESP32. Во время загрузки и сброса вывод ESP32 — вход,
поэтому на порту **высокий уровень**. Нужно, чтобы в этом состоянии SSR был
**выключен**. Значит, активный уровень — **LOW**: SSR включается, только когда
ESP32 сам тянет вывод к земле.

## Схема (один канал)

Входная часть (сторона платы, 3,3 В):

```
            на плате KC868-A8                 │  модуль ключа
                                              │
  +3V3 ──[4k7]──┐                             │
                │                             │
  GPIO ──[100]──┴──── DATA порта TEM/HUMI ────┼──[R1 330]──┐
                                              │            │
                                              │          ──┴──  катод (2)
                                              │           /▲\   LED оптрона U1 (PC817), ток анод → катод
                                              │          ──┬──  анод (1)
                                              │            │
  +3V3 (P19, «3V») ───────────────────────────┼────────────┘
  GND ────────────────────────────────────────┼──── GND (общий с 12 В)
```

Выходная часть (сторона 12 В):

```
  +12V ──────────────┬───────────────────────┐
                     │                       │
                     │ коллектор U1 (4)      │
                    U1  фототранзистор       SSR вход «+»
                     │ эмиттер U1 (3)        SSR вход «−»
                     │                       │
                     ├──[R2 100]──┐          │
                     │            │ G        │ D
                  [R3 10k]       Q1 (2N7002 / AO3400)
                     │            │ S        │
                    GND          GND ────────┘ (через канал Q1)
```

Q1 включён на стороне «−» SSR: сток → «−» SSR, исток → GND.
Индикатор (необязательно): R4 2,2 кОм + светодиод параллельно входу SSR.

Если коротко: `+3V3 → LED оптрона → R1 → порт → (100 Ом) → GPIO`.
Ток через светодиод оптрона идёт, **только если GPIO = LOW**.
Выход оптрона открывает MOSFET, тот замыкает «−» SSR на землю, на «+» SSR подано +12 В.

## Номиналы

| Поз. | Номинал | Зачем |
|---|---|---|
| U1 | PC817 (или аналог, CTR ≥ 50 %) | Развязка: SSR включается только при активном токе от GPIO |
| R1 | 330 Ом | Ток светодиода ≈ (3,3 − 1,2 − 0,1) / (330 + 100) ≈ 4,6 мА. GPIO выдерживает |
| R2 | 100 Ом | Ограничение тока заряда затвора |
| R3 | 10 кОм | Подтяжка затвора к GND: без сигнала MOSFET закрыт |
| Q1 | 2N7002 или AO3400 (logic-level, V<sub>GS</sub> ≥ 20 В) | Ток входа SSR (обычно 7–15 мА) от 12 В |
| R4 + LED1 | 2,2 кОм + светодиод (необязательно) | Индикатор «SSR включён», запитан параллельно входу SSR |

Оптрон PC817 при токе 4,6 мА и CTR ≥ 50 % даёт ≥ 2,3 мА. Этого с запасом хватает,
чтобы поднять затвор до ≈ 11,8 В через R3 = 10 кОм (нужно 1,2 мА).

Питание +3,3 В для анода оптрона берётся с разъёма P19 (контакт «3V»).
Ток ≈ 5 мА на канал. Важно, чтобы это был **тот же** 3,3 В, что питает подтяжку порта.

## Поведение во всех состояниях

| Ситуация | Уровень на порту | Ток LED оптрона | SSR |
|---|---|---|---|
| Загрузка/сброс ESP32, вывод — вход | 3,3 В (подтяжка) | 0 | **ВЫКЛ** |
| Прошивка выдаёт «выкл» (вывод = HIGH) | 3,3 В | 0 | **ВЫКЛ** |
| Прошивка выдаёт «вкл» (вывод = LOW) | ≈ 0,1 В | ≈ 4,6 мА | ВКЛ |
| Обрыв провода порт ↔ модуль | — | 0 | **ВЫКЛ** |
| Пропало питание 3,3 В / 12 В | — | 0 | **ВЫКЛ** |
| ESP32 завис с выводом в LOW | ≈ 0 В | есть | ВКЛ → сторожевой таймер перезагружает ESP32 → ВЫКЛ. Перегрев перекрывают аппаратные термостаты |

В прошивке выходы объявлены с `inverted: true`: логическое «выкл» = вывод в HIGH.
Это совпадает с состоянием при загрузке.

## Что проверить на стенде (до подключения ТЭНа)

1. Осциллографом на портах 1 и 2 при включении питания и при нажатии RESET.
   Про GPIO14 известно, что ESP32 может выдавать на нём импульсы при загрузке.
   Если на порту 1 есть провалы в LOW, поменять местами каналы (ТЭН на GPIO13)
   или добавить RC-фильтр (10 кОм / 10 мкФ) на входе модуля.
   Импульс короче 10 мс через zero-cross SSR даст не больше одного полупериода сети.
2. Мультиметром: светодиод индикатора SSR не загорается при загрузке и в «Стоп».
3. Падение напряжения на SSR при 6,5 А ≈ 1–1,5 В → ≈ 8–10 Вт тепла. Нужен радиатор.

## Силовая часть (напоминание)

```
L ── автомат ── термостат +100 °C (ручной сброс) ── термостат +50 °C (автовозврат) ── SSR ── ТЭН ── N
```

Рекомендация: питать силовую цепь SSR ТЭНа через общий провод контактов
скоростей приточного вентилятора (K1–K3) или через контактор, который включён
только вместе с вентилятором. Тогда ТЭН физически не получит питание
без работающего притока.
