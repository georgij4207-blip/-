# Чек-лист стенда

Проверка платы, модуля ключей и прошивки **до** выезда на объект. Силовая часть
(моторы, ТЭНы) на стенде **не подключается**: вместо нагрузок — индикаторы ключей SSR
(или SSR без нагрузки), вместо датчиков — резисторы. Отмечать `[x]`, отклонения записывать.

Имена сущностей — как в веб-интерфейсе платы (`http://<IP>/`).

## Резисторы-имитаторы датчиков (NTC 10k B3380)

| Резистор | Температура | Для чего |
|---|---|---|
| 10 кОм | +25 °C | норма |
| 30 кОм | −1,7 °C | выброс: преднагрев, обмерзание |
| 5,6 кОм | +41 °C | приток: «нагрев не управляется» (горячо, но < 45 °C) |
| 4,3 кОм | +49 °C | приток: перегрев (> 45 °C) |
| нет (обрыв) | — | обрыв датчика |
| перемычка | — | КЗ датчика |

## 0. Подготовка

- [ ] `firmware/secrets.yaml` заполнен (Wi-Fi, пароли, ключи `openssl rand -base64 32`).
- [ ] `esphome config ris400p.yaml` — «Configuration is valid».
- [ ] `esphome compile ris400p.yaml` — без ошибок.
- [ ] Прошивка по USB: `esphome run ris400p.yaml`.

## 1. Питание и загрузка (только плата, БП 12 В)

- [ ] 12 В подано: ни одно реле не щёлкнуло.
- [ ] Ток от БП при всех реле выключенных ____ мА (ориентир 100–250 мА), при всех включённых ____ мА.
- [ ] Мультиметр на портах TEM/HUMI 1 и 2 (DATA–GND): ≈ 3,3 В и при загрузке, и после.
- [ ] Лог загрузки: строка `Профиль: приточно-вытяжная; приток: AC, отводы обмотки; …`.
- [ ] Нет строки `Ошибка конфигурации`.
- [ ] «status Состояние установки» = «Стоп» (или авария датчиков, если они ещё не подключены — это нормально).

## 2. Шина I2C

- [ ] Лог i2c-скана: найдены **0x22** (входы), **0x24** (реле). Другие адреса →
      поправить `pcf_inputs_address` / `pcf_relays_address` в `ris400p.yaml`.
- [ ] После подключения ADS1115: найден **0x48**.

## 3. Реле вручную

В `ris400p.yaml` временно: `relays_internal: "false"`, `vent_logic_enabled: "false"`.

- [ ] K1…K8 по очереди: щелчок, индикатор реле, прозвонка COM–NO замыкается.
- [ ] Включить K1, затем K2: K1 выключается, через ~1,5 с включается K2. То же K4/K5/K6.
- [ ] Перезагрузка (кнопка «restart»): все реле выключены.
- [ ] Вернуть `relays_internal: "true"`, `vent_logic_enabled: "true"`, прошить.

## 4. Входы X1–X8

- [ ] Каждый Xn замкнуть на GND: сущность «Xn … (замкнут)» = Включено.
- [ ] Ток входа: амперметр между X1 и GND — ____ мА (ожидаем ≈ 5,4 мА).
- [ ] Для дальнейших проверок поставить перемычки на GND: X1 (вместо KL1), X2, X3, X4, X8.

## 5. Модуль ключей SSR (`ssr_driver.md`)

Подключить J1 (3V3, GND, CH1, CH2), J2 (12 В), J4 — к SSR **без нагрузки**
(или к светодиодам с 2,2 кОм). J3 (реле давления) — пока разомкнут.

- [ ] Без потока (J3 разомкнут): индикаторы SSR **не горят** ни в каком режиме.
- [ ] Осциллограф на CH1 и CH2 (относительно GND): при включении питания и при RESET
      **нет провалов в LOW**. Есть провалы на CH1 (GPIO14) → RC 10 кОм / 10 мкФ или
      поменять каналы местами. Записать: ______________________
- [ ] 10 раз выключить/включить питание: индикаторы SSR ни разу не мигнули.
- [ ] Отключить кабель J1: индикаторы не горят.
- [ ] Замкнуть J3 (имитация потока): «X7 Поток притока (замкнут)» = Включено.
- [ ] Напряжение на входе SSR (3–4) при включённом канале: ≈ 11–12 В.
- [ ] Предохранитель F1 вынуть: X7 = Выключено.

Для проверок 7–9 поток удобно имитировать перемычкой на J3. Предупреждение
«Реле давления замкнуто при остановленном притоке» через 60 с стоянки — ожидаемо, это проверка залипания реле.

## 6. Датчики (`ntc_inputs.md`)

- [ ] «vref Опорное 3,3 В делителей» ≈ 3,3 В, совпадает с мультиметром на шине 3V3 ± 0,02 В.
- [ ] 10 кОм на каждый вход (t_outdoor, t_exhaust, t_extract, t_supply): 25,0 ± 0,5 °C.
- [ ] Штатные/запасные NTC: показания совпадают с эталонным термометром ± 1 °C;
      разница → `t_*_offset`. Записать: ___________________
- [ ] Каждый вход без датчика: «обрыв», температура пустая, «неисправность» = Вкл.
- [ ] t_supply без датчика: «t_supply Приток: напряжение» = ____ В. Порог `adc_open_ratio` × 3,30
      должен быть хотя бы на 0,05 В ниже этого значения (по умолчанию 3,04 В).
- [ ] Каждый вход перемычкой на GND: «КЗ».
- [ ] Отключить ADS1115 от P19: через ~5 с у трёх датчиков ADS «нет данных»,
      t_supply продолжает показывать.

## 7. Вентиляция (по щелчкам реле и «fan_state Состояние вентиляции»)

Все датчики — 10 кОм, перемычки X1–X4, X8, J3 замкнут.

- [ ] «mode» = Скорость 2: K7 вкл → через 30 с K5 → через 3 с K2 → «Работа».
- [ ] Скорость 3: K2 выкл, через 1,5 с K3 (и K5 → K6).
- [ ] «exhaust_offset» = −1: вытяжка на ступень ниже; на Скорости 1 вытяжка остаётся 1.
- [ ] Стоп: «Продувка» 120 с → K3 выкл → через 3 с K6 выкл → через 15 с K7 выкл.
- [ ] Во время продувки выбрать Скорость 2: сразу «Работа».
- [ ] Перезагрузка в режиме «Скорость 2»: через 10 с полный пуск с заслонки.

## 8. Нагрев (SSR без нагрузки)

- [ ] «setpoint» = 30 °C (выше 25 °C резистора): через 10 с после пуска притока
      «heater_pct Мощность нагрева» растёт, индикатор SSR1 мигает с периодом 10 с.
- [ ] Смена ступени: на время паузы и 10 с после — нагрев 0.
- [ ] Стоп: нагрев 0 сразу, продувка идёт.
- [ ] «heating_enable Нагрев притока (зима)» выкл: нагрев 0, вентиляция работает.
- [ ] 30 кОм на t_exhaust: «preheater Преднагреватель» = Вкл, индикатор SSR2 горит;
      10 кОм обратно — выкл.
- [ ] J3 разомкнуть во время нагрева: оба SSR гаснут сразу (аппаратно), сразу же
      «Нет потока притока» (приток работает дольше 30 с), продувка, стоп, ручной сброс.
- [ ] J3 разомкнут с самого пуска: нагрев не включается, через 30 с работы притока
      «Нет потока притока».

## 9. Защиты (`alarms.md`)

После каждой аварии: убрать причину → «alarm_reset Сброс аварий».

| | Действие | Ожидаем |
|---|---|---|
| [ ] | X8 снять перемычку (пожар) | сразу все реле выкл, K7 выкл без выбега, SSR выкл, K8 выкл; «Сброс» при разомкнутом X8 не снимает |
| [ ] | X4 снять (внешний стоп) | продувка 120 с, стоп; K8 **остаётся** вкл; после возврата перемычки — пуск сам |
| [ ] | X1 снять (термостат +100 °C) | SSR1 выкл сразу, продувка, стоп, K8 выкл; нужен ручной сброс |
| [ ] | X1 снять → перезагрузить до сброса | после загрузки установка в стопе, авария «ожидает сброса» |
| [ ] | 4,3 кОм на t_supply (перегрев) | «Перегрев притока», нагрев 0, продувка **не заканчивается**, пока приток > 35 °C; через 3 мин ещё «Нагрев не управляется» → вентиляторы на 3-ю ступень (горячо без команды) |
| [ ] | 5,6 кОм на t_supply, уставка 10 °C | через ~3 мин «Нагрев не управляется»: вентиляторы на 3-ю ступень и не останавливаются даже в «Стоп» |
| [ ] | Снять любой датчик (обрыв) | нагрев 0, продувка, стоп; вернуть — пуск сам |
| [ ] | 30 кОм на t_exhaust надолго (обмерзание)* | каждые 10 мин шаг: приток ниже → вытяжка выше → только вытяжка → через 30 мин стоп с аварией |
| [ ] | X2 снять (фильтр) | предупреждение, установка работает, K8 вкл |

\* Для ускорения временно `frost_step_ms: "60000"`, `exhaust_only_max_ms: "180000"`
в `ris400p.yaml`, после проверки вернуть.

## 9a. Экран и CO2 (`display_co2.md`)

- [ ] i2c-скан: найдены **0x3C** (OLED) и **0x62** (SCD41).
- [ ] Напряжение 3V на P19 при работе SCD41 и Wi-Fi: ≥ 3,2 В.
- [ ] Экран: три страницы сменяются каждые 5 с, кириллица читается, строки не вылезают.
- [ ] При аварии (снять X4 — не авария; снять датчик — авария): заголовок «!…», каждая вторая страница — аварии.
- [ ] «co2 CO2» ≈ 400–600 ppm на свежем воздухе, растёт, если подышать на датчик.
- [ ] «rh Влажность вытяжки» — правдоподобная.
- [ ] Режим «Авто»: подышать на датчик (> 1100 ppm) → через ~1 мин «auto_level Авто: ступень» = 3,
      вентиляция переходит на 3; через ~10 мин после проветривания — обратно.
- [ ] Отключить SCD41 в «Авто»: через ~2 мин предупреждение «Нет данных CO2», ступень 2,
      «fault Авария» не включается.

## 10. Журнал, время, перезагрузка

- [ ] «journal_dump Журнал аварий в лог»: события с датой и временем (NTP).
- [ ] Без интернета: время в журнале «[+N с]».
- [ ] Выключить питание платы на 1 мин: режим, уставка, Kp/Ti, журнал и несброшенные аварии сохранились.

## 11. Сеть

- [ ] Без Wi-Fi: через ~1 мин точка доступа `ris400p-setup`, страница настройки Wi-Fi.
- [ ] Веб-интерфейс просит логин/пароль.
- [ ] Home Assistant находит устройство, ключ API подходит.
- [ ] Обновление по воздуху (OTA) проходит.

## 12. Перед выездом

- [ ] Все временные параметры возвращены (`relays_internal`, `vent_logic_enabled`,
      `frost_step_ms`, `exhaust_only_max_ms`), прошивка залита заново.
- [ ] Перемычки X1–X4, X8, J3 сняты (на объекте — реальные сигналы или перемычки на XT8).
- [ ] Записаны: адреса I2C, напряжение обрыва t_supply, поправки датчиков, импульсы GPIO14.
