# Salda RIS 400P (400 м³/ч) — модульная сборка на универсальной платформе

Вместо KC868-A8 + ADS1115 + самодельного модуля ключей SSR: плата **Waveshare ESP32-S3-ETH-8DI-8RO**
и два готовых модуля Modbus. Паять ничего не нужно — только монтаж на DIN.

Прошивка: объект `firmware/ris400p_modular.yaml`, профиль `firmware/profiles/salda_ris400p_modular.yaml`.
Логика, защиты, параметры, назначение реле K1–K8 и входов X1–X8 — **те же**, что у сборки на KC868-A8
(`profiles/salda_ris400p.yaml`); драйверы ТЭНа и рекуператора — те же, меняется только выход.

## 1. Что поменялось относительно KC868-A8

| Узел | KC868-A8 | Модульная сборка |
|---|---|---|
| Контроллер | KC868-A8, Wi-Fi | Waveshare ESP32-S3-ETH-8DI-8RO, **Ethernet**, часы, RS-485 |
| Питание щита управления | 12 В DC | **24 В DC** (плата 7–36 В, модули 24 В) |
| Реле K1–K8, входы X1–X8 | на плате | на плате, то же назначение |
| Катушки KM1–KM7 | 12 В DC | **24 В DC** |
| Датчики NTC (4 шт.) | ADS1115 + делители, вход GPIO36 | модуль аналоговых входов, каналы 1–4 |
| ТЭН 1,5 кВт | SSR1 с ШИМ от GPIO14 через ключ | **регулятор мощности 0–10 В** от канала 1 модуля 0–10 В |
| Преднагреватель 0,6 кВт | SSR2 от GPIO13 через ключ | **регулятор / реле с входом 0–10 В** от канала 2 (вкл = 10 В, выкл = 0) |
| Блокировка нагрева без потока | ДР даёт +12V_FLOW на входы SSR, оптрон U3 → X7 | ДР включает контактор **KM8 «разрешение нагрева»** (питание обоих регуляторов), доп. контакт KM8 → X7 |
| CO2 / экран | SCD41, OLED по I2C | нет; CO2 — резерв (канал 5 модуля входов, 0–10 В); экран — пульт, следующий этап |
| Диспетчеризация | нет | Modbus RTU на втором RS-485 (карта — `universal_platform.md`, 3.5) |

## 2. Подключение

**Плата Waveshare** (назначение как у KC868-A8, `panel_wiring.md`, `fan_wiring.md`):

| Реле / вход | Назначение |
|---|---|
| K1–K3 | катушки KM1–KM3 — ступени притока |
| K4–K6 | катушки KM4–KM6 — ступени вытяжки |
| K7 | катушка KM7 — привод заслонки |
| K8 | «норма» — сухой контакт наружу |
| X1 | KL1 после термостата ТЭНа +100 °C |
| X2, X3 | реле давления фильтров (или перемычки) |
| X4 | внешний стоп (или перемычка) |
| X5 | KL2 после термостата ТЭНа +50 °C |
| X6 | KL3 после термостата преднагревателя |
| X7 | **доп. контакт KM8** (поток притока есть) |
| X8 | пожар (или перемычка) |

Цепочка NC-контактов KM1–KM6 (взаимная блокировка ступеней) — как в `fan_wiring.md`, только
катушки 24 В DC. Как подключать сухой контакт к входам DI платы (своё питание входов или
внешние 24 В) — **проверить по вики Waveshare** до монтажа.

**Модули на шине RS-485 №1** (клеммы RS-485 платы, витая пара в экране, терминаторы 120 Ом на концах):

| Модуль | Адрес | Канал | Подключение |
|---|---|---|---|
| 0–10 В (МУ110-224.6У) | 12 | 1 | вход 0–10 В регулятора ТЭНа |
| | | 2 | вход 0–10 В регулятора преднагревателя |
| | | 3–6 | резерв |
| Аналоговые входы (МВ110-224.8А) | 14 | 1 | датчик наружного воздуха |
| | | 2 | датчик притока |
| | | 3 | датчик вытяжки из помещения |
| | | 4 | датчик выброса (после рекуператора) |
| | | 5–8 | резерв (CO2 0–10 В, давление) |

Адреса и скорость (38400, 8N1) задать модулям конфигуратором до монтажа (адаптер USB↔RS-485).

**Силовая часть 230 В** — как у KC868-A8 (`panel_wiring.md`), кроме нагрева:

```
QF2 ─ KM8.1 ─ SK1 (термостат ТЭНа, ручной сброс) ─ регулятор ТЭНа ─ ТЭН 1,5 кВт
                                                  └ катушка KL1 (контроль SK1 → X1)
QF3 ─ KM8.2 ─ SK2 (термостат преднагр., ручной сброс) ─ регулятор преднагр. ─ преднагреватель 0,6 кВт
                                                  └ катушка KL3 (контроль SK2 → X6)
+24 В ─ F ─ ДР (реле давления притока) COM→NO ─ катушка KM8 (24 В DC) ─ 0 В
KM8 доп. контакт NO ─ вход X7
```

Нет потока — KM8 отпадает и снимает питание с обоих регуляторов, даже если контроллер завис.
Термостаты SK1/SK2 рвут силовую цепь сами. Программа дублирует обе защиты.

## 3. Сборка прошивки

1. Получить паспорт модуля аналоговых входов и заполнить в `ris400p_modular.yaml` регистры
   `ai_reg`, `ai_reg_step`, `ai_value_type`, `ai_register_type`, `ai_multiply`.
   Без них сборка остановится — это сделано намеренно.
2. Модуль 0–10 В МУ110-224.6У задан по руководству: регистры 0–5, 0…1000.
3. `esphome run ris400p_modular.yaml` — первый раз по USB-C, дальше по сети.

Проверено: с пробными регистрами конфигурация и компиляция проходят (RAM 21,9 %, Flash 7,8 %).
Сборка Salda на KC868-A8 после выделения общей части драйверов не изменилась.

## 5. Что уточнить до заказа

1. **Датчики.** Прозвонить штатные NTC Salda (сопротивление при 25 °C, B) и проверить по паспорту
   модуля входов, поддерживает ли он такой NTC. Если нет — датчики Pt1000 (п. 37) рядом со штатными.
2. **Регистры модуля входов** — из паспорта (п. 3 раздела 3).
3. **Регулятор мощности:** входное сопротивление входа 0–10 В — не меньше допустимой нагрузки выхода
   модуля 0–10 В (по паспортам обоих).
4. **Входы DI Waveshare:** схема подключения сухого контакта (вики Waveshare).
5. Термостаты SK1/SK2, KL2, реле давления фильтров, привод заслонки — по результатам прозвонки установки.
