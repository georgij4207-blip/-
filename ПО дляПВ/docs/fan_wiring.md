# Подключение вентиляторов: аппаратная блокировка скоростей

Реле K1–K8 на KC868-A8 — SPDT, у каждого три клеммы: COM, NO, NC.
Ниже обозначение `K3.NC` = клемма NC реле K3 на плате.

Какой отвод обмотки даёт какую скорость, определить прозвонкой и пробным пуском.
Цвета проводов в документации на RIS 400P неизвестны, поэтому здесь не указаны.

## Принцип

Фаза идёт по цепочке через нормально замкнутые контакты: K3 → K2 → K1.
Включённое реле старшей ступени отрезает фазу от всех младших. Даже если прошивка
ошибётся и включит два реле сразу, фаза попадёт только на **один** отвод (старший).
Отводы обмотки никогда не замкнутся между собой через реле.

## Приток (K1–K3)

```
L ──[QF/FU 2 А, хар. C или T]──► K3.COM
                                 K3.NO ─────────────────► отвод «скорость 3» мотора притока
                                 K3.NC ──► K2.COM
                                           K2.NO ───────► отвод «скорость 2» мотора притока
                                           K2.NC ──► K1.COM
                                                     K1.NO ─► отвод «скорость 1» мотора притока
                                                     K1.NC ─  не подключать

N ─────────────────────────────────────────────────────► N мотора притока
Рабочий конденсатор мотора — по штатной схеме мотора, не трогаем.
PE ────────────────────────────────────────────────────► корпус мотора
```

## Вытяжка (K4–K6)

```
L ──[QF/FU 2 А, хар. C или T]──► K6.COM
                                 K6.NO ─────────────────► отвод «скорость 3» мотора вытяжки
                                 K6.NC ──► K5.COM
                                           K5.NO ───────► отвод «скорость 2» мотора вытяжки
                                           K5.NC ──► K4.COM
                                                     K4.NO ─► отвод «скорость 1» мотора вытяжки
                                                     K4.NC ─  не подключать

N ─────────────────────────────────────────────────────► N мотора вытяжки
PE ────────────────────────────────────────────────────► корпус мотора
```

## Таблица состояний (для притока; для вытяжки K6/K5/K4 так же)

| K3 | K2 | K1 | Фаза на отводе |
|---|---|---|---|
| выкл | выкл | выкл | нет (стоп) |
| выкл | выкл | вкл | скорость 1 |
| выкл | вкл | любое | скорость 2 |
| вкл | любое | любое | скорость 3 |

Ошибочные комбинации (два и более реле включены) безопасны: работает старшая ступень.

## Замечания

- **RC-снабберы** 0,1 мкФ X2 275 В~ + 100 Ом — между каждым отводом и N (RC1–RC6) и на приводе
  заслонки (RC7), в щите на клеммах (`panel_wiring.md`, раздел 3). Без них искра при размыкании
  индуктивной нагрузки на контактах K1–K7 даёт помехи, которые могут перезагружать ESP32.
  Ставятся на нагрузку, а не на контакты: через выключенный контакт не течёт ток утечки.

- Ток через контакты: один мотор, 0,92 А (пусковой больше). Это далеко от 10 А.
- SPDT переключает «разрыв перед замыканием», поэтому при переходе 3 → 2 есть
  момент без фазы. Пауза в прошивке (`fan_interlock_wait`, 1,5 с) остаётся:
  она даёт мотору сбросить обороты и не создаёт бросков тока.
- Защитный автомат или предохранитель на каждый мотор: 2 А, характеристика C
  (автомат) или T (плавкий предохранитель), под пусковой ток.
- Внешний стоп (X4) отрабатывает прошивка. Если нужен аппаратный аварийный стоп,
  его контакт ставят в цепь L перед `K3.COM` / `K6.COM` и перед автоматами ТЭНов.

## Остальные реле

```
K7 (заслонка):  L ──► K7.COM;  K7.NO ──► привод заслонки «открыть»
                (для привода с пружинным возвратом. Для 3-проводного привода
                 «открыть/закрыть» K7.NC ──► «закрыть»)

K8 (норма, fail-safe):  K8.COM / K8.NO — сухой контакт «всё в порядке» (замкнут = норма).
                        Разомкнут = авария или контроллер выключен/перезагружается.
```
