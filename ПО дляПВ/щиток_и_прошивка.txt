# Схема подключения щитка

Щит управления Salda RIS 400P на плате KinCony KC868-A8. Номиналы и позиции —
`docs/bom.md`. Подробности узлов: ключ SSR — `ssr_driver.md`, блокировка скоростей —
`fan_wiring.md`, датчики — `ntc_inputs.md`.

> **Названия клемм платы** (12V/GND, K1…K8 COM/NO/NC, X1…X8, GND входов, P19, порты
> TEM/HUMI) взяты из описания платы. Перед монтажом сверить с шелкографией своей
> платы. Распиновку портов TEM/HUMI (где DATA, где GND, есть ли 3,3 В) — прозвонить.
> **Сеть 230 В, работа под напряжением запрещена.** Монтаж силовой части — электрик с допуском.

## 1. Общая структура

```
                       ┌──────────────────────────── ЩИТ ───────────────────────────────────┐
 Сеть 230 В ──► XT1 ──►│ QF1 дифавтомат 16 А 30 мА ──► шины L / N, шина PE                  │
                       │   ├─ QF2 10 А ── T100 ─┬─ T50 ─┬─ SSR1 ──────────────► XT4 ТЭН      │
                       │   │                    KL1→X1  KL2→X5                               │
                       │   ├─ QF3 6 А  ── T прд. ─────── SSR2 ──────────────► XT5 преднагрев │
                       │   ├─ QF4 2 А  ── цепочка K3→K2→K1 ── RC1–RC3 ──────► XT2 мотор притока
                       │   ├─ QF5 2 А  ── цепочка K6→K5→K4 ── RC4–RC6 ──────► XT3 мотор вытяжки
                       │   └─ QF6 2 А  ─┬─ БП 12 В ── плата KC868-A8, модуль ключей          │
                       │                └─ K7 ── RC7 ──────────────────────► XT6 заслонка    │
                       │  Плата ◄── XT7 датчики NTC, XT8 входы, реле давления                │
                       │  ADS1115 + делители, модуль ключей SSR, реле KL1, KL2 (230 В)       │
                       └────────────────────────────────────────────────────────────────────┘
```

- Термостаты ТЭНа и преднагревателя стоят **в установке** (у нагревателей), их провода
  заведены в щит, и в силовой цепи они стоят **до SSR**. Термостат разрывает питание
  нагревателя независимо от SSR, даже если SSR пробит.
- Срабатывание термостатов ТЭНа прошивка видит через интерфейсные реле KL1, KL2 с катушкой 230 В.
  Подключение — в двух вариантах, раздел 3.1. Термостат преднагревателя — раздел 3.2.
- RC-снабберы (0,1 мкФ + 100 Ом) стоят на отводах моторов и приводе заслонки. Они гасят искру
  на контактах K1–K7, иначе помехи могут перезагружать ESP32.

Датчики по каналам — таблица в разделе 4 («Датчики температуры»), входы — «Дискретные входы X1–X8».

- Перемычки на XT8, если датчика или сигнала нет: 36–37, 38–39, 40–41, 42–43. Вход NC без
  перемычки = авария (так и задумано: обрыв провода = авария). Что нужно — **УТОЧНИТЬ при
  прозвонке** (`site_survey.md`).
- **XT8.44–45 не вход платы.** Это +12 В цепи потока: ДР замыкает +12 В в +12V_FLOW, оптрон U3
  модуля ключей передаёт это на X7 (J5). С X8 (42–43) и K8 (46–47) клеммы не связаны.
  Между 43 и 44 и между 45 и 46 — **разделительные пластины**: 43 — GND платы, и случайная
  перемычка 43–44 закоротит +12 В через F1.
- **K8 (46–47) — сухой контакт**, гальванически не связан ни с платой, ни с +12 В. Наружу —
  только безопасное низкое напряжение (сигнал диспетчеризации, ≤ 24 В). Если внешней цепи нужно
  230 В — K8 вывести на отдельные клеммы в силовой группе, не в XT8. Нужен ли K8 наружу —
  **УТОЧНИТЬ** у заказчика.

## 3. Силовая часть 230 В

```
XT1.1 L ──► QF1 (1P+N, 16 А, C, 30 мА, тип A) ──► шина L
XT1.2 N ──► QF1 N ──────────────────────────────► шина N
XT1.3 PE ───────────────────────────────────────► шина PE (корпус щита, DIN-рейка)

ТЭН:
шина L ──► QF2 10 А C ──► XT4.14 ──[термостаты ТЭНа, раздел 3.1]── XT4.16 ──► SSR1 клемма 1
SSR1 клемма 2 ──► XT4.17 ──► ТЭН ──► XT4.18 ──► шина N

Преднагреватель:
шина L ──► QF3 6 А C ──► XT5.20 ──[термостат преднагревателя, раздел 3.2]── XT5.21 ──► SSR2 клемма 1
SSR2 клемма 2 ──► XT5.22 ──► преднагреватель ──► XT5.23 ──► шина N

Моторы (RC — снабберы 0,1 мкФ + 100 Ом между отводом и N, в щите на клеммах):
шина L ──► QF4 2 А C ──► K3.COM … цепочка K3→K2→K1 … ──► XT2.4/5/6;  XT2.7 ──► шина N
              RC1: XT2.4–XT2.7    RC2: XT2.5–XT2.7    RC3: XT2.6–XT2.7
шина L ──► QF5 2 А C ──► K6.COM … цепочка K6→K5→K4 … ──► XT3.9/10/11; XT3.12 ──► шина N
              RC4: XT3.9–XT3.12   RC5: XT3.10–XT3.12  RC6: XT3.11–XT3.12

Питание и заслонка:
шина L ──► QF6 2 А C ──┬──► БП 12 В: L
                       └──► K7.COM;  K7.NO ──► XT6.25 ──► привод заслонки ──► XT6.26 ──► шина N
                                              RC7: XT6.25–XT6.26
шина N ────────────────────► БП 12 В: N
```

- **SSR**: у типовых SSR-25DA клеммы 1–2 — нагрузка ~230 В, 3 (+) и 4 (−) — управление
  3–32 В DC. Сверить с маркировкой своего SSR. Каждый SSR — на радиатор с термопастой.
- **RC-снабберы** стоят между нагрузкой и N, а не параллельно контактам. Так через выключенный
  контакт не идёт ток утечки (≈ 7 мА через 0,1 мкФ), и отвод выключенного мотора не оказывается
  под напряжением.
- Конденсаторы моторов остаются в установке, по заводской схеме мотора.

### 3.1 Термостаты ТЭНа

Термостаты стоят в установке, в щит заведены их провода. В силовой цепи они стоят до SSR1.
Какой вариант на объекте — **УТОЧНИТЬ при прозвонке** (`site_survey.md` 3.3).

#### Вариант А: два термостата (KL1 на X1, KL2 на X5)

Каждый термостат выведен отдельно: доступен провод между +100 °C и +50 °C. Профиль: `th50_enabled: "true"`.

```
шина L ──► QF2 ──► XT4.14 ──[T +100 °C, ручной сброс]── XT4.15 ──[T +50 °C, автовозврат]── XT4.16 ──► SSR1 клемма 1
                                                          │                                 │
                                                       KL1 A1                            KL2 A1
                                                       KL1 A2 ──► шина N                 KL2 A2 ──► шина N
                                                       KL1 NO (11–14) ──► X1 / GND       KL2 NO (11–14) ──► X5 / GND
```

| Клемма / реле | Подключение |
|---|---|
| XT4.14 | L от QF2 → вход термостата +100 °C |
| XT4.15 | выход +100 °C = вход +50 °C; катушка KL1 (A1), A2 — на шину N |
| XT4.16 | выход +50 °C → SSR1 клемма 1; катушка KL2 (A1), A2 — на шину N |
| KL1 NO (11–14) | X1 и GND входов: разомкнут → авария «Сработал аварийный термостат ТЭНа», ручной сброс |
| KL2 NO (11–14) | X5 и GND входов: разомкнут → ТЭН запрещён, предупреждение, автосброс |

#### Вариант Б: один общий провод (KL1 на XT4.16, KL2 не ставить, th50_enabled: "false")

Оба термостата последовательно внутри установки, выведены только вход и выход цепи.
Профиль: `th50_enabled: "false"`, вход X5 не используется.

```
шина L ──► QF2 ──► XT4.14 ──[T +100 °C и T +50 °C, общая цепь в установке]── XT4.15 ──перемычка── XT4.16 ──► SSR1 клемма 1
                                                                                                    │
                                                                                                 KL1 A1
                                                                                                 KL1 A2 ──► шина N
                                                                                                 KL1 NO (11–14) ──► X1 / GND
```

| Клемма / реле | Подключение |
|---|---|
| XT4.14 | L от QF2 → вход общей цепи термостатов |
| XT4.15 | выход общей цепи термостатов |
| XT4.15–16 | перемычка |
| XT4.16 | → SSR1 клемма 1; катушка KL1 (A1), A2 — на шину N |
| KL1 NO (11–14) | X1 и GND входов: срабатывание любого термостата → авария, ручной сброс |
| KL2 | не ставить |

#### Для обоих вариантов

- Контакты KL: у Finder 38.51 (CO) нормально открытый — **11–14** (11 — общий, 14 — NO,
  12 — NC не используется). У другого реле — сверить по маркировке.
- KL1 и KL2 обесточиваются и при выключенном QF2. Отключение автомата ТЭНа прошивка покажет как
  «Сработал аварийный термостат ТЭНа». Это безопасная сторона: нагрев не включится.
- Ручной сброс у +100 °C — аппаратный, в установке.

### 3.2 Термостат преднагревателя — уточнить при прозвонке

Есть ли у преднагревателя свой термостат — **УТОЧНИТЬ при прозвонке** (`site_survey.md` 3.3).

**Есть в установке** — заводится на XT5.20–21, последовательно до SSR2:

```
шина L ──► QF3 ──► XT5.20 ──[термостат преднагревателя, в установке]── XT5.21 ──► SSR2 клемма 1
```

**Нет** — поставить капиллярный или биметаллический термостат с ручным сбросом (`bom.md`, раздел E)
у преднагревателя и завести так же на XT5.20–21. До его установки — перемычка XT5.20–21, **только временно**:

```
шина L ──► QF3 ──► XT5.20 ──перемычка (временно)── XT5.21 ──► SSR2 клемма 1
```

По желанию прошивка может видеть срабатывание: реле KL3, катушка на XT5.21 и шину N, контакт
NO (11–14) → X6, в профиле `preheat_th_enabled: "true"` (сейчас `"false"`).

### Цепочка блокировки скоростей (реле SPDT платы)

```
QF4 ─► K3.COM;  K3.NO ─► XT2.6 (скор. 3);  K3.NC ─► K2.COM
                K2.NO ─► XT2.5 (скор. 2);  K2.NC ─► K1.COM
                K1.NO ─► XT2.4 (скор. 1);  K1.NC — не подключать

QF5 ─► K6.COM;  K6.NO ─► XT3.11 (скор. 3); K6.NC ─► K5.COM
                K5.NO ─► XT3.10 (скор. 2); K5.NC ─► K4.COM
                K4.NO ─► XT3.9  (скор. 1); K4.NC — не подключать
```

Какой отвод мотора — какая скорость, определить прозвонкой (`docs/site_survey.md`).
Перемычки между реле — провод 0,75 мм² с наконечниками НШВИ.

## 4. Низковольтная часть 12 В / 3,3 В

### Питание

```
БП 12 В: +V ──► плата «12V»
             ──► модуль ключей J2.1 (+12 В)
         −V ──► плата «GND»
             ──► модуль ключей J2.2 (GND)
```

Минус БП — общий для платы, модуля ключей, ADS1115. PE на минус 12 В не подключать.

### Разъём P19 платы (I2C и 3,3 В)

| P19 | → ADS1115 (0x48) | → OLED SSD1306 (0x3C) | → SCD41 (0x62) | → модуль ключей | → делители |
|---|---|---|---|---|---|
| 3V | VDD | VCC | VDD | J1.1 (+3V3, аноды оптронов U1, U2) | верх делителей 22 кОм и 1 кОм на A3 |
| GND | GND, ADDR | GND | GND | J1.2 | |
| SDA | SDA | SDA | SDA | | |
| SCL | SCL | SCL | SCL | | |

OLED — на дверце или лицевой панели щита (шлейф ≤ 30 см). SCD41 — в канале вытяжки у щита,
провод I2C ≤ 1 м (`display_co2.md`).

### Датчики температуры: датчик — канал — клеммы — пин

Источник — `firmware/profiles/salda_ris400p.yaml` (`t_*_channel`, `t_supply_pin`, `ads_vref_channel`).
Если схема расходится с этой таблицей, правится схема, а не прошивка.

| Датчик | Где | Канал (профиль) | Клеммы XT7 (сигнал / GND) | Пин платы |
|---|---|---|---|---|
| t_extract | вытяжка из помещения | ADS1115 **A0** (`t_extract_channel: A0_GND`) | **32** / 33 | ADS1115 0x48 по I2C: P19 SDA = GPIO4, SCL = GPIO5 |
| t_exhaust | выброс после рекуператора | ADS1115 **A1** (`t_exhaust_channel: A1_GND`) | **30** / 31 | то же (ADS1115 0x48) |
| t_outdoor | наружный воздух | ADS1115 **A2** (`t_outdoor_channel: A2_GND`) | **28** / 29 | то же (ADS1115 0x48) |
| опорное 3,3 В | — | ADS1115 **A3** (`ads_vref_channel: A3_GND`) | — (в щите: 1 кОм от P19 «3V») | то же (ADS1115 0x48) |
| t_supply | приток в помещение | ESP32 ADC1 (`t_supply_pin: GPIO36`) | **34** / 35 | порт TEM/HUMI **3**: DATA = GPIO36, GND порта |
| резерв | — | ESP32 ADC1 GPIO39 | — | порт TEM/HUMI 4 |

Где именно стоит каждый датчик в установке — **УТОЧНИТЬ** при прозвонке (`site_survey.md`).

### Дискретные входы платы X1–X8: вход — клемма — норма — прошивка

Вход активен при замыкании на GND платы: внешний контакт — между клеммой Xn и GND входов.
Входы — PCF8574 0x22, биты 0–7 = X1–X8 (`boards/kc868_a8.yaml`); тип контакта и назначение —
`profiles/salda_ris400p.yaml`. «NC» в прошивке = **норма — контакт замкнут** (обрыв = авария).

| Вход | Клемма / источник | Норма | Прошивка (профиль → действие) |
|---|---|---|---|
| X1 | KL1 NO (11–14) в щите; катушка KL1 — XT4.15 (после +100 °C) | замкнут: после +100 °C есть 230 В | `th100_input: in_x1`, NC → разомкнут: «Сработал аварийный термостат ТЭНа» — нагрев выкл, продувка, стоп, **ручной сброс** |
| X2 | XT8.36 (→ X2) / 37 (GND); реле фильтра притока или перемычка | замкнут | `filter_supply_input: in_x2`, NC → разомкнут: предупреждение «Засорён фильтр притока» |
| X3 | XT8.38 / 39; реле фильтра вытяжки или перемычка | замкнут | `filter_exhaust_input: in_x3`, NC → разомкнут: предупреждение «Засорён фильтр вытяжки» |
| X4 | XT8.40 / 41; внешний стоп или перемычка | замкнут | `ext_stop_input: in_x4`, NC → разомкнут: продувка, стоп; K8 остаётся «норма»; после замыкания — пуск сам |
| X5 | KL2 NO (11–14) в щите; катушка KL2 — XT4.16 (после +50 °C) | замкнут: после +50 °C есть 230 В | `th50_input: in_x5`, NC, `th50_enabled: "true"` → разомкнут: ТЭН запрещён, предупреждение «Сработал термостат ТЭНа +50 °C», **автосброс**. Один общий провод: KL2 нет, `th50_enabled: "false"`, X5 не читается |
| X6 | резерв: KL3 NO, катушка — XT5.21 (после термостата преднагревателя), **по желанию** | замкнут | `preheat_th_input: in_x6`, NC; сейчас `preheat_th_enabled: "false"` — **не читается**, перемычка не нужна. При `"true"`: разомкнут → преднагрев запрещён, предупреждение, автосброс |

## 5. Размещение в щите (рекомендация)

- DIN-рейка 1: QF1…QF6, БП 12 В.
- DIN-рейка 2: плата KC868-A8 (на DIN-держателе или стойках), модуль ключей, ADS1115 с платой делителей.
- Монтажная панель / рейка 3: SSR1, SSR2 на радиаторах (низом к вентиляционным отверстиям),
  реле KL1, KL2 (KL3).
- RC-снабберы RC1–RC7 — прямо на клеммах XT2, XT3, XT6 (готовые RC-гасители в корпусе или
  на клеммной колодке), выводы как можно короче.
- Клеммник XT — внизу щита; силовые (XT1–XT6) и слаботочные (XT7–XT8) — разнесены,
  разделитель. Провода датчиков не вести в одном жгуте с силовыми.
- Щит не меньше 24 модулей, IP31+; SSR греются (≈ 10 Вт у ТЭНа) — оставить зазор сверху.

## Схема

### Цепь +12V_FLOW (питание выходных ступеней, есть только при потоке)

```
 +12V ──[F1 0,5 А]──► ДР.COM          ДР.NO ──┬─────────────────► +12V_FLOW
                      реле перепада давления   │                  (на оба канала SSR)
                      притока (NO: замкнут =   │
                      поток есть)              └──[R7 680]─┐
                                                           │ анод (1)
                                                      U3 PC817, LED
                                                           │ катод (2)
                                                          GND

                         U3 коллектор (4) ─────► X7 (вход платы)
                         U3 эмиттер  (3)  ─────► GND платы
```

### Канал ТЭНа (канал преднагревателя такой же: GPIO13, U2, Q2, SSR2)

Входная ступень:

```
        плата KC868-A8               │  модуль ключа
                                     │
 +3V3 ──[4k7]──┐                     │
               │                     │
 GPIO14 ─[100]─┴── DATA порта 1 ─────┼──[R1 330]──► U1 катод (2)
                                     │                  │  LED U1 (PC817), ток анод → катод
 +3V3 (P19, «3V») ───────────────────┼────────────► U1 анод (1)
 GND ────────────────────────────────┼──── GND модуля (общий с 12 В)
```

Выходная ступень:

```
 +12V_FLOW ──┬──────────────────────────┬────────────────┐
             │                          │                │
        U1 коллектор (4)            SSR1 «+»          [R4 2k2]
        U1 эмиттер (3)              SSR1 «−»            │
             │                          │              LED1 (индикатор, необязательно)
             │                          │                │
             │                          ├────────────────┘
             │                          │
             ├──[R2 100]──► затвор Q1   └──► сток Q1
             │                                (Q1: BS170 / 2N7002 / AO3400)
          [R3 10k]                  исток Q1
             │                          │
 GND ────────┴──────────────────────────┘
```

Логика: LOW на GPIO14 → ток через LED U1 → транзистор U1 подаёт +12V_FLOW на затвор Q1 →
Q1 замыкает «−» SSR1 на GND → SSR1 включён (если +12V_FLOW есть, то есть поток есть).

## Номиналы

| Поз. | Номинал | Назначение |
|---|---|---|
| U1, U2 | PC817 (CTR ≥ 50 %) | Входная ступень, работает только при активном LOW |
| R1 | 330 Ом, 0,125 Вт | Ток LED ≈ (3,3 − 1,2 − 0,1) / (330 + 100) ≈ 4,6 мА, для GPIO допустимо |
| R2 | 100 Ом | Ограничение тока перезаряда затвора |
| R3 | 10 кОм | Подтяжка затвора к GND: без сигнала Q1 закрыт |
| Q1, Q2 | BS170 (TO-92, для макетки), 2N7002 или AO3400 (SMD) | V<sub>GS</sub> max ≥ 20 В при 12 В на затворе; ток входа SSR 7–15 мА |
| R4 + LED1 | 2,2 кОм + светодиод (необязательно) | Индикатор «SSR включён», параллельно входу SSR |
| U3 | PC817 | Передаёт наличие +12V_FLOW на вход X7 |
| R7 | 680 Ом, 0,25 Вт (1206) или 0,5 Вт | Ток LED U3 ≈ 15,9 мА, 0,17 Вт: U3 в насыщении при токе входа X7 5,4 мА (расчёт ниже); заодно ток смачивания контакта реле давления |
| F1 | 0,5 А | Защита цепи +12V_FLOW |

Расчёт: U1 при 4,6 мА и CTR ≥ 50 % даёт ≥ 2,3 мА. Чтобы поднять затвор Q1 до ≈ 11,8 В
через R3 = 10 кОм, нужно 1,2 мА, запас двукратный.

Ток по +3,3 В с разъёма P19: ≈ 5 мА на канал. Анод оптрона питать от **той же** шины 3,3 В,
что питает подтяжку порта. Иначе в состоянии «выкл» через LED потечёт ток.

## Реле перепада давления притока

- Контакт NO реле давления замыкается при наличии потока и подаёт +12 В в цепь
  +12V_FLOW. От неё питаются выходные ступени **обоих** ключей и входы «+» обоих SSR.
  Без потока SSR физически не получают управления, что бы ни делала прошивка.
- Оптрон U3 следит за самой цепью +12V_FLOW и замыкает вход X7 на GND.
  Прошивка видит «поток есть» = X7 замкнут. Обрыв провода реле давления и
  перегорание F1 прошивка тоже видит как «нет потока» — по принципу NC
  (обрыв = авария).
- Ток входа X7 по схеме платы: V12 → 2 кОм → LED оптрона EL357 → клемма,
  при замыкании на GND ≈ (12 − 1,2) / 2000 ≈ 5,4 мА. Этот ток идёт через транзистор U3.
- Расчёт R7. U3 должен быть в насыщении при I<sub>C</sub> = 5,4 мА.
  CTR PC817 без группы ≥ 50 %, с запасом на старение и нагрев (×0,7) — 35 %.
  I<sub>F</sub> ≥ 5,4 / 0,35 ≈ 15,4 мА → R7 = (12 − 1,2) / 15,4 мА ≈ 700 Ом → **680 Ом**:
  I<sub>F</sub> ≈ 15,9 мА (PC817 допускает 50 мА), P ≈ 0,17 Вт.
  С PC817 группы C (CTR 200–400 %) хватит 2,2 кОм (≈ 4,9 мА).
- Через контакт реле давления идёт ≈ 60 мА (U3 16 мА + 2 SSR до 15 мА + индикаторы + затворы). Для таких слаботочных цепей лучше реле
  с позолоченными контактами. Если их нет, ток через R7 поддерживает контакт чистым.
- В прошивке (шаг 5): после пуска притока даётся задержка на раскрутку
  (параметр, по умолчанию 30 с). Если за это время X7 не замкнулся или потом
  разомкнулся, это авария «Нет потока притока»: нагрев выключается, продувка, стоп.

## Подключение

Оба модуля — на шине I2C разъёма P19, вместе с ADS1115 (новых пинов не нужно).

| P19 | OLED SSD1306 (0x3C) | SCD41 (0x62) | ADS1115 (0x48) |
|---|---|---|---|
| 3V | VCC | VDD | VDD |
| GND | GND | GND | GND, ADDR |
| SDA | SDA | SDA | SDA |
| SCL | SCL | SCL | SCL |

- Шина работает на 100 кГц (предел PCF8574). Провод до SCD41 — **не длиннее ~1 м**.
- У каждого модуля обычно свои подтяжки SDA/SCL 4,7–10 кОм. С тремя модулями
  суммарно ≈ 2–3 кОм — допустимо. Если на стенде шина «сбоит», снять подтяжки с одного модуля.
- SCD41 в момент измерения берёт до ~200 мА от 3,3 В. На стенде проверить, что 3,3 В
  платы не проседает (ESP32 с Wi-Fi + SCD41): ≥ 3,2 В на P19.

**Где ставить SCD41.** В канал вытяжки у щита (через отверстие в воздуховоде или в
коробке, продуваемой вытяжным воздухом). Вытяжка — это смесь воздуха из всех комнат,
её CO2 — хороший средний показатель. Нужен датчик в комнате на длинном кабеле — вместо
SCD41 Senseair S8 по UART (`packages/sensors/co2_senseair_s8.yaml`); для него нужны два
свободных пина (RX/TX), они в проекте не заданы — их надо выбрать и указать.

          static vent::SignalIn *filt_s = vent::esph::in(id(${filter_supply_input}), "${filter_supply_contact}");
          static vent::SignalIn *filt_e = vent::esph::in(id(${filter_exhaust_input}), "${filter_exhaust_contact}");

          vent::VentInputs in;
          const size_t idx = id(vent_mode).active_index().value_or(0);
          in.mode = idx > ${fan_levels} ? vent::MODE_AUTO : (uint8_t) idx;  // последний пункт — «Авто»
          in.exhaust_offset = (int) id(exhaust_offset).state;
          in.t_outdoor = id(${t_outdoor_sensor}).state;
          in.t_supply = id(${t_supply_sensor}).state;
          in.t_extract = id(${t_extract_sensor}).state;
          in.t_exhaust = id(${t_exhaust_sensor}).state;
          in.co2_ppm = id(${co2_sensor}).state;
          in.humidity = id(${humidity_sensor}).state;
          in.fire_ok = fire->ok();
          in.ext_stop_ok = ext_stop->ok();
          in.flow_ok = flow->ok();
          in.filter_supply_ok = filt_s->ok();
          in.filter_exhaust_ok = filt_e->ok();
          esphome::Component *io_in[] = { ${io_check_inputs} };
          esphome::Component *io_out[] = { ${io_check_outputs} };
          in.io_ok = true;
          for (auto *c : io_in) in.io_ok &= !c->is_failed() && !c->status_has_warning();
          for (auto *c : io_out) in.io_ok &= !c->is_failed() && !c->status_has_warning();
          in.heating_enabled = id(heating_enable).state;
          in.setpoint = id(supply_setpoint).state;
          auto t = id(sntp_time).now();
          in.unix_time = (${ntp_enabled} && t.is_valid()) ? t.timestamp : 0;

          sys.update(now, in);

          // --- Журнал: новые записи в лог и во флеш ---
          auto &al = sys.alarms();
          static uint32_t logged = al.journal_total();
          char buf[200];
          while (logged < al.journal_total()) {
            const int back = (int) (al.journal_total() - 1 - logged);
            logged++;
            if (back >= al.journal_count()) continue;
            vent::format_journal_entry(al.journal(back), buf, sizeof(buf));
            ESP_LOGW("protect", "%s", buf);
            if (back == 0) id(last_event_text).publish_state(buf);
          }
          if (al.take_dirty()) {
            al.export_journal(id(alarm_journal_store).data());
            id(alarm_latched_store) = al.latched_mask();
          }

          // --- Тексты состояния (публикуются только при изменении) ---
          sys.status_text(buf, sizeof(buf));
          if (id(vent_status_text).state != buf) id(vent_status_text).publish_state(buf);
          const char *fs = sys.fans().state_text();
          if (id(fan_state_text).state != fs) id(fan_state_text).publish_state(fs);
          std::string list;
          for (uint8_t c = 1; c < vent::AL_COUNT; c++) {
            if (!al.on(c)) continue;
            if (!list.empty()) list += "; ";
            list += vent::alarm_def(c).text;
            if (al.waiting_reset(c)) list += " (ожидает сброса)";
          }
          if (list.empty()) list = "нет";
          if (list.size() > 250) {  // лимит Home Assistant; режем по границе символа UTF-8
            size_t cut = 247;
            while (cut > 0 && (list[cut] & 0xC0) == 0x80) cut--;
            list = list.substr(0, cut) + "...";
          }
          if (id(alarms_text).state != list) id(alarms_text).publish_state(list);

#pragma once
// Аварии, предупреждения и журнал событий. Общая таблица для системы и всех драйверов:
// новый драйвер с новой аварией добавляет код в конец перечисления.
//
// Каждая авария: текст, сброс (ручной/авто), действие. Ручные (latched) аварии
// остаются взведёнными после пропадания причины до нажатия «Сброс», и только если
// причины уже нет. Взведённые аварии и журнал сохраняются во флеш (через прошивку).

#include <cstdint>
#include <cstdio>
#include <ctime>

namespace vent {

// Коды не переставлять: маска взведённых аварий хранится во флеше по номерам битов.
enum AlarmCode : uint8_t {
  AL_NONE = 0,
  AL_FIRE,                // X8 пожарная сигнализация
  AL_THERMOSTAT,          // X1 аварийный термостат ТЭНа (+100 °C)
  AL_OVERHEAT,            // программный перегрев притока
  AL_NO_FLOW,             // X7 нет потока притока
  AL_FROST,               // обмерзание: полный стоп
  AL_SENSOR_OUTDOOR,
  AL_SENSOR_SUPPLY,
  AL_SENSOR_EXHAUST,
  AL_SENSOR_EXTRACT,
  AL_OUTDOOR_LOW,         // t_outdoor ниже допустимого
  AL_EXT_STOP,            // X4 внешний стоп
  AL_FILTER_SUPPLY,       // X2
  AL_FILTER_EXHAUST,      // X3
  AL_HEAT_INSUFFICIENT,   // ТЭН долго на максимуме, уставка не достигается
  AL_THERMOSTAT50,        // X5 термостат +50 °C (опционально)
  AL_PREHEAT_THERMOSTAT,  // X6 термостат преднагревателя (опционально)
  AL_FROST_EXHAUST_ONLY,  // обмерзание: приток остановлен, оттайка вытяжкой
  AL_FROST_REDUCED,       // обмерзание: приток снижен
  AL_FLOW_STUCK,          // реле давления замкнуто при остановленном притоке
  AL_IO_FAULT,            // нет связи с PCF8574 (входы/реле)
  AL_HEAT_UNCONTROLLED,   // приток греется при выключенном нагреве (пробит SSR?)
  AL_CONFIG,              // профиль: драйвер не задан, не реализован или не подходит к типу установки
  AL_DAMPER,              // заслонка не открылась (по концевику)
  AL_CO2_SENSOR,          // авторежим без данных CO2
  AL_COUNT
};

enum class AlarmAction : uint8_t {
  NONE,             // только сообщение
  BLOCK_HEATER,     // запрет основного ТЭНа
  BLOCK_PREHEATER,  // запрет преднагревателя
  STOP,             // нагрев выкл, продувка, стоп установки
  FIRE,             // по параметру: немедленный стоп без продувки или стоп с продувкой
  COOL,             // нагрев выкл, вентиляторы на максимум и не останавливать
};

struct AlarmDef {

};

enum JournalEvent : uint8_t { EV_RAISED = 1, EV_CLEARED = 2, EV_RESET = 3 };

struct JournalEntry {
  uint32_t unix_time;  // 0 — время по NTP неизвестно
  uint32_t uptime_s;
  uint8_t code;
  uint8_t event;
};

static const int JOURNAL_SIZE = 20;
// Хранение во флеше: 1 слово — счётчик, далее по 3 слова на запись.
static const int JOURNAL_WORDS = 1 + JOURNAL_SIZE * 3;

class Alarms {
 public:
  // Состояние причины. Возвращает true, если что-то изменилось (для журнала и флеша).
  void set(uint8_t code, bool condition, uint32_t uptime_s, uint32_t unix_time) {
    const uint32_t bit = 1u << code;
    const bool was = active_ & bit;
    if (condition && !was) {
      active_ |= bit;
      if (alarm_def(code).latched)
        latched_ |= bit;
      log_(code, EV_RAISED, uptime_s, unix_time);
    } else if (!condition && was) {
      active_ &= ~bit;
      log_(code, EV_CLEARED, uptime_s, unix_time);
    }
  }

  // Ручной сброс: снимаются взведённые аварии, причины которых уже нет.
  void reset(uint32_t uptime_s, uint32_t unix_time) {
    const uint32_t cleared = latched_ & ~active_;
    for (uint8_t c = 1; c < AL_COUNT; c++)
      if (cleared & (1u << c))
        log_(c, EV_RESET, uptime_s, unix_time);
    latched_ &= active_;
    if (cleared)
      dirty_ = true;
  }

  bool on(uint8_t code) const { return (active_ | latched_) & (1u << code); }
  // Причины уже нет, авария ждёт ручного сброса.
  bool waiting_reset(uint8_t code) const { return (latched_ & ~active_) & (1u << code); }
  uint32_t on_mask() const { return active_ | latched_; }
  uint32_t latched_mask() const { return latched_; }
  bool any_latched() const { return latched_ != 0; }

  bool any_action(AlarmAction a) const {
    for (uint8_t c = 1; c < AL_COUNT; c++)
      if (on(c) && alarm_def(c).action == a)
        return true;
    return false;
  }
  bool any_fault() const {
    for (uint8_t c = 1; c < AL_COUNT; c++)
      if (on(c) && alarm_def(c).fault)
        return true;
    return false;
  }

  // Самая важная из включённых: сначала аварии, потом предупреждения; среди них меньший код.
  uint8_t top() const {
    for (uint8_t c = 1; c < AL_COUNT; c++)
      if (on(c) && alarm_def(c).fault)
        return c;
    for (uint8_t c = 1; c < AL_COUNT; c++)
      if (on(c))
        return c;
    return AL_NONE;
  }

  // --- журнал ---
  int journal_count() const { return count_ < JOURNAL_SIZE ? count_ : JOURNAL_SIZE; }
  // i = 0 — самая свежая запись
  const JournalEntry &journal(int i) const {
    const int idx = ((int) (count_ % JOURNAL_SIZE) - 1 - i + 2 * JOURNAL_SIZE) % JOURNAL_SIZE;
    return ring_[idx];
  }
  uint32_t journal_total() const { return count_; }

  // --- сохранение во флеш ---
  bool take_dirty() {
    const bool d = dirty_;
    dirty_ = false;
    return d;
  }
  void export_journal(uint32_t *words) const {
    words[0] = count_;
    for (int i = 0; i < JOURNAL_SIZE; i++) {
      words[1 + i * 3] = ring_[i].unix_time;
      words[2 + i * 3] = ring_[i].uptime_s;
      words[3 + i * 3] = (uint32_t) ring_[i].code | ((uint32_t) ring_[i].event << 8);
    }
  }
  void import(const uint32_t *words, uint32_t latched) {
    count_ = words[0];
    for (int i = 0; i < JOURNAL_SIZE; i++) {
      ring_[i].unix_time = words[1 + i * 3];
      ring_[i].uptime_s = words[2 + i * 3];
      ring_[i].code = words[3 + i * 3] & 0xFF;
      ring_[i].event = (words[3 + i * 3] >> 8) & 0xFF;
    }
    // взведённые до перезагрузки аварии остаются до ручного сброса
    latched_ = latched & ((1u << AL_COUNT) - 1);
    for (uint8_t c = 1; c < AL_COUNT; c++)
      if (!alarm_def(c).latched)
        latched_ &= ~(1u << c);
  }

 private:
  void log_(uint8_t code, uint8_t event, uint32_t uptime_s, uint32_t unix_time) {
    JournalEntry &e = ring_[count_ % JOURNAL_SIZE];
    e.unix_time = unix_time;
    e.uptime_s = uptime_s;
    e.code = code;
    e.event = event;
    count_++;
    dirty_ = true;
  }

  uint32_t active_{0};
  uint32_t latched_{0};
  JournalEntry ring_[JOURNAL_SIZE]{};
  uint32_t count_{0};
  bool dirty_{false};
};

inline const char *journal_event_text(uint8_t ev) {
  switch (ev) {
    case EV_RAISED: return "возникла";
    case EV_CLEARED: return "причина устранена";
    case EV_RESET: return "сброшена";
    default: return "?";
  }
}

// «2026-10-30 21:15:03 Перегрев притока — возникла» или «[+3605 с] …» без NTP.
inline void format_journal_entry(const JournalEntry &e, char *buf, size_t n) {
  char when[32];
  if (e.unix_time != 0) {
    time_t t = (time_t) e.unix_time;
    struct tm tm_local;
    localtime_r(&t, &tm_local);
    strftime(when, sizeof(when), "%Y-%m-%d %H:%M:%S", &tm_local);
  } else {
    snprintf(when, sizeof(when), "[+%lu с]", (unsigned long) e.uptime_s);
  }
  snprintf(buf, n, "%s %s — %s", when, alarm_def(e.code).text, journal_event_text(e.event));
}

#pragma once
// Авторежим: ступень вентиляции по CO2 (и подъём по влажности).
//
//  CO2 ≤ co2_level2            → ступень 1
//  co2_level2 < CO2 ≤ level3   → ступень 2
//  CO2 > co2_level3            → ступень 3
// Вниз — с гистерезисом co2_hyst. Влажность выше rh_boost_above → не ниже rh_boost_level
// (снятие ниже rh_boost_above − rh_boost_hyst).
// Чтобы ступень не «прыгала»: вверх — если новая ступень держится up_delay_ms,
// вниз — down_delay_ms. Первое показание после пуска применяется сразу.
// Нет данных CO2 → резервная ступень fallback_level (система выдаёт предупреждение).

#include <cmath>
#include <cstdint>

namespace vent {

struct AutoSpeedConfig {
  float co2_level2{800.0f};   // ppm
  float co2_level3{1100.0f};  // ppm
  float co2_hyst{50.0f};
  bool rh_enabled{true};
  float rh_boost_above{70.0f};  // %
  float rh_boost_hyst{5.0f};
  uint8_t rh_boost_level{3};
  uint32_t up_delay_ms{60000};
  uint32_t down_delay_ms{600000};
  uint8_t fallback_level{2};
};

class AutoSpeed {
 public:
  void configure(const AutoSpeedConfig &cfg) { cfg_ = cfg; }

  // Сброс при выходе из авторежима: следующее включение начнёт с текущих показаний.
  void reset() {
    init_ = false;
    missing_ = false;
  }

  uint8_t update(uint32_t now, float co2, float rh, uint8_t max_level) {
    const uint8_t top = max_level < 3 ? max_level : 3;
    if (std::isnan(co2)) {
      missing_ = true;
      init_ = false;
      level_ = clamp_(cfg_.fallback_level, top);
      return level_;
    }
    missing_ = false;

    // ступень по CO2: вверх по порогам, вниз — с гистерезисом от текущей
    const uint8_t up = 1 + (co2 > cfg_.co2_level2) + (co2 > cfg_.co2_level3);
    const uint8_t down = 1 + (co2 > cfg_.co2_level2 - cfg_.co2_hyst) + (co2 > cfg_.co2_level3 - cfg_.co2_hyst);
    uint8_t want = init_ ? co2_level_ : up;
    if (up > want) want = up;
    else if (down < want) want = down;
    co2_level_ = want;

    // влажность
    if (cfg_.rh_enabled && !std::isnan(rh)) {
      if (rh > cfg_.rh_boost_above) rh_high_ = true;
      else if (rh < cfg_.rh_boost_above - cfg_.rh_boost_hyst) rh_high_ = false;
    } else {
      rh_high_ = false;
    }
    if (rh_high_ && cfg_.rh_boost_level > want)
      want = cfg_.rh_boost_level;
    want = clamp_(want, top);

    if (!init_) {
      init_ = true;
      level_ = want;
      pending_ = want;
      return level_;
    }
    if (want == level_) {
      pending_ = want;
      return level_;
    }
    if (want != pending_) {  // новое направление — отсчёт заново
      pending_ = want;
      pending_since_ = now;
    }
    const uint32_t delay = want > level_ ? cfg_.up_delay_ms : cfg_.down_delay_ms;
    if (now - pending_since_ >= delay)
      level_ = want;
    return level_;
  }

  uint8_t level() const { return level_; }
  bool sensor_missing() const { return missing_; }
  bool humidity_boost() const { return rh_high_; }

 private:
  static uint8_t clamp_(uint8_t l, uint8_t top) { return l < 1 ? 1 : (l > top ? top : l); }

  AutoSpeedConfig cfg_{};
  bool init_{false};
  bool missing_{false};
  bool rh_high_{false};
  uint8_t co2_level_{1};
  uint8_t level_{1};
  uint8_t pending_{1};
  uint32_t pending_since_{0};
};

}  // namespace vent

#pragma once
// Нагрев: ПИ-регулятор температуры притока (выход 0…100 % на slow_pwm SSR ТЭНа)
// и гистерезис преднагревателя.

#include <cmath>

namespace vent {

inline float clampf(float x, float lo, float hi) { return x < lo ? lo : (x > hi ? hi : x); }

// ПИ с anti-windup:
//  - интегратор ограничен 0…out_max;
//  - интегрирование останавливается, когда выход уже в насыщении в сторону ошибки
//    (условное интегрирование). При 1,5 кВт на 400 м³/ч ТЭН поднимает приток
//    максимум на ≈ 11 °C: в мороз выход часто стоит на 100 %, и без этого интегратор
//    «накопил» бы лишнее и дал перерегулирование, когда уставка станет достижимой.
class PiController {
 public:
  void reset() {
    integral_ = 0.0f;
    output_ = 0.0f;
  }

  // kp — %/°C, ti_s — с (0 = без И-составляющей), out_max — %, dt_s — шаг, с.
  float update(float setpoint, float measured, float kp, float ti_s, float out_max, float dt_s) {
    if (std::isnan(setpoint) || std::isnan(measured) || dt_s <= 0.0f) {
      reset();
      return 0.0f;
    }
    const float error = setpoint - measured;
    const float p = kp * error;
    float candidate = integral_;
    if (ti_s > 0.0f)
      candidate += kp * error * dt_s / ti_s;
    const float unclamped = p + candidate;
    const bool saturated_high = unclamped > out_max && error > 0.0f;
    const bool saturated_low = unclamped < 0.0f && error < 0.0f;
    if (!saturated_high && !saturated_low)
      integral_ = candidate;
    integral_ = clampf(integral_, 0.0f, out_max);
    output_ = clampf(p + integral_, 0.0f, out_max);
    return output_;
  }

  float output() const { return output_; }
  float integral() const { return integral_; }

 private:
  float integral_{0.0f};
  float output_{0.0f};
};

// Преднагреватель: вкл ниже on_below, выкл выше off_above.
class Hysteresis {
 public:
  bool update(float value, float on_below, float off_above) {
    if (std::isnan(value)) {
      state_ = false;
    } else if (value < on_below) {
      state_ = true;
    } else if (value > off_above) {
      state_ = false;
    }
    return state_;
  }
  void reset() { state_ = false; }
  bool state() const { return state_; }

 private:
  bool state_{false};
};

}  // namespace vent

#pragma once
// Привод с пружинным возвратом: питание подано — открывается, снято — пружина закрывает.
// Открытой считается через open_ms после команды или по концевику (если задан).
// С концевиком: не открылась за 2 × open_ms → авария «Заслонка не открылась».

#include "alarms.h"
#include "damper.h"

namespace vent {

class SpringDamper : public DamperDriver {
 public:
  SpringDamper(DigitalOut *out, uint32_t open_ms, SignalIn *open_switch = nullptr)
      : out_(out), open_ms_(open_ms), open_switch_(open_switch) {}

  const char *type_name() const override { return "Привод вкл/выкл с пружинным возвратом"; }

  void command(bool open) override {
    if (open && !cmd_)
      since_ = now_;  // отсчёт времени открытия — с момента команды (now_ — текущий цикл)
    cmd_ = open;
    out_->set(open);  // закрытие — сразу (пожар), открытие — тоже сразу
  }

  // Вызывается в начале каждого цикла, до последовательности пуска.
  void update(uint32_t now, AlarmSink &alarms) override {
    now_ = now;
    out_->set(cmd_);
    const bool late = open_switch_ && cmd_ && !open_switch_->ok() && now - since_ >= 2 * open_ms_;
    alarms.set(AL_DAMPER, late);
  }

  bool is_open() const override {
    if (!cmd_)
      return false;
    if (open_switch_)
      return open_switch_->ok();
    return now_ - since_ >= open_ms_;
  }
  bool commanded_open() const override { return cmd_; }

 private:
  DigitalOut *out_;
  uint32_t open_ms_;
  SignalIn *open_switch_;
  bool cmd_{false};
  uint32_t since_{0};
  uint32_t now_{0};
};

}  // namespace vent

 public:
  static const uint8_t MAX_TAPS = 5;

  // taps[0] — реле ступени 1 … taps[n-1] — ступени n.
  AcTapsFan(DigitalOut *const *taps, uint8_t n, uint32_t pause_ms) : pause_ms_(pause_ms) {
    n_ = n > MAX_TAPS ? MAX_TAPS : n;
    for (uint8_t i = 0; i < n_; i++)
      taps_[i] = taps[i];
  }

  const char *type_name() const override { return "AC, отводы обмотки"; }
  uint8_t levels() const override { return n_; }
  void set_target(uint8_t level) override { target_ = level > n_ ? n_ : level; }

  void update(uint32_t now) override {
    if (active_ != target_) {
      if (active_ != 0) {
        active_ = 0;
        off_since_ = now;
        pause_pending_ = true;
      } else if (!pause_pending_ || now - off_since_ >= pause_ms_) {
        pause_pending_ = false;
        active_ = target_;
      }
    }
    // Сначала выключения, потом включение — на выходах не бывает двух ступеней.
    for (uint8_t i = 0; i < n_; i++)
      if (active_ != i + 1)
        taps_[i]->set(false);
    if (active_ > 0)
      taps_[active_ - 1]->set(true);
  }

  uint8_t active_level() const override { return active_; }
  bool settled() const override { return active_ == target_; }

 private:
  DigitalOut *taps_[MAX_TAPS]{};
  uint8_t n_{0};
  uint8_t target_{0};
  uint8_t active_{0};
  uint32_t pause_ms_;
  uint32_t off_since_{0};
  bool pause_pending_{false};
};

}  // namespace vent

#pragma once
// Электрический ТЭН через SSR с медленным ШИМ (slow_pwm), ПИ-регулятор по t_supply.
// Защиты драйвера:
//  - вход аварийного термостата +100 °C (ручной сброс) → авария со стопом;
//  - вход термостата +50 °C (опц.) → запрет ТЭНа, пока разомкнут;
//  - «не хватает мощности»: выход на максимуме долго, уставка не достигается;
//  - «нагрев не управляется»: команда 0, а приток горячее улицы и помещения (пробит SSR).

#include "alarms.h"
#include "control_math.h"
#include "heater.h"

namespace vent {

struct ElectricPwmConfig {
  float out_max{100.0f};               // %
  float full_pct{98.0f};
  uint32_t insufficient_ms{900000};
  float insufficient_band{2.0f};       // °C ниже уставки
  float uncontrolled_margin_c{8.0f};
  uint32_t uncontrolled_ms{180000};
};

class ElectricPwmHeater : public HeaterDriver {
 public:
  // ssr — выход slow_pwm; kp/ti — настраиваемые на лету параметры ПИ;
  // th100 — аварийный термостат (nullptr — не подключён); th50 — опционально.
  ElectricPwmHeater(AnalogOut *ssr, AnalogIn *kp, AnalogIn *ti, SignalIn *th100, SignalIn *th50,
                    const ElectricPwmConfig &cfg)
      : ssr_(ssr), kp_(kp), ti_(ti), th100_(th100), th50_(th50), cfg_(cfg) {}

  const char *type_name() const override { return "Электро, SSR с ШИМ"; }
  bool needs_airflow() const override { return true; }

  void update(const HeatContext &c, AlarmSink &alarms) override {
    const bool th100_open = th100_ && !th100_->ok();
    const bool th50_open = th50_ && !th50_->ok();
    alarms.set(AL_THERMOSTAT, th100_open);
    alarms.set(AL_THERMOSTAT50, th50_open);

    const bool on = c.heat_allowed && c.airflow_ok && !th100_open && !th50_open &&
                    !std::isnan(c.t_supply) && !std::isnan(c.setpoint);
    if (on) {
      out_ = pi_.update(c.setpoint, c.t_supply, kp_->value(), ti_->value(), cfg_.out_max, c.dt_s);
    } else {
      pi_.reset();
      out_ = 0.0f;
    }
    ssr_->set(out_ / 100.0f);

    const bool at_max = on && out_ >= cfg_.full_pct && c.t_supply < c.setpoint - cfg_.insufficient_band;
    if (!at_max)
      max_since_ = c.now_ms;
    alarms.set(AL_HEAT_INSUFFICIENT, c.now_ms - max_since_ >= cfg_.insufficient_ms);

    // Тепло без команды: приток работает, ТЭН и преднагрев выключены, а воздух горячее
    // и улицы, и помещения.
    float t_ref = NAN;
    if (!std::isnan(c.t_outdoor)) t_ref = c.t_outdoor;
    if (!std::isnan(c.t_extract) && (std::isnan(t_ref) || c.t_extract > t_ref)) t_ref = c.t_extract;
    const bool uncontrolled = out_ == 0.0f && !c.preheat_active && c.supply_running_ms >= 60000 &&
                              !std::isnan(c.t_supply) && !std::isnan(t_ref) &&
                              c.t_supply > t_ref + cfg_.uncontrolled_margin_c;
    if (!uncontrolled)
      uncontrolled_since_ = c.now_ms;
    alarms.set(AL_HEAT_UNCONTROLLED, c.now_ms - uncontrolled_since_ >= cfg_.uncontrolled_ms);
  }

  float output_pct() const override { return out_; }
  const PiController &pi() const { return pi_; }

 private:
  AnalogOut *ssr_;
  AnalogIn *kp_, *ti_;
  SignalIn *th100_, *th50_;
  ElectricPwmConfig cfg_;
  PiController pi_{};
  float out_{0.0f};
  uint32_t max_since_{0};
  uint32_t uncontrolled_since_{0};
};

}  // namespace vent

====================================================================================================
#pragma once
// Пластинчатый рекуператор (перекрёстный или противоточный) с электрическим
// преднагревателем. Защита от обмерзания по t_exhaust (выброс после рекуператора).
//
// Преднагреватель: вкл ниже preheat_on_below, выкл выше preheat_off_above (только при потоке).
// Лестница: шаг вниз — t_exhaust < frost_c дольше step_ms; шаг назад — > recover_c дольше recover_ms.
//  1) приток на ступень ниже (вытяжка как есть) — пока приток > 1;
//  2) вытяжка на ступень выше — пока вытяжка < максимума;
//  3) только вытяжка — не дольше exhaust_only_max_ms, затем стоп с аварией.
// forbid_imbalance (котёл/колонка/камин): приток и вытяжка снижаются вместе, без шагов 2–3;
// снижать некуда — стоп с аварией.

#include "alarms.h"
#include "control_math.h"
#include "recuperator.h"

namespace vent {

struct PlateRecuperatorConfig {
  float preheat_on_below{1.0f};
  float preheat_off_above{3.0f};
  float frost_c{0.0f};
  float recover_c{3.0f};
  uint32_t step_ms{600000};
  uint32_t recover_ms{600000};
  uint32_t exhaust_only_max_ms{1800000};
  bool forbid_imbalance{false};
  uint8_t max_level{3};  // максимальная ступень вентиляторов
};

// Скорости на уровне защиты level. last_level (если не nullptr) — номер последнего уровня.
inline FanRequest frost_ladder(FanRequest r, int level, bool forbid_imbalance, uint8_t max_level,
                               int *last_level) {
  if (r.supply == 0) {
    if (last_level) *last_level = 0;
    return r;
  }
  int s = r.supply, e = r.exhaust, lvl = 0;
  const int reduce_steps = s - 1;
  const int boost_steps = forbid_imbalance ? 0 : (int) max_level - e;
  const int total = reduce_steps + (boost_steps > 0 ? boost_steps : 0) + (forbid_imbalance ? 0 : 1);
  if (last_level) *last_level = total;
  for (; lvl < level && lvl < reduce_steps; lvl++) {
    s--;
    if (forbid_imbalance && e > 1) e--;
  }
  for (; lvl < level && lvl < reduce_steps + boost_steps; lvl++)
    e++;
  if (lvl < level && !forbid_imbalance)
    s = 0;
  r.supply = (uint8_t) s;
  r.exhaust = (uint8_t) e;
  return r;
}

class PlateRecuperator : public RecuperatorDriver {
 public:
  // preheater — SSR преднагревателя (nullptr — нет); preheat_thermostat — опц. термостат.
  PlateRecuperator(DigitalOut *preheater, SignalIn *preheat_thermostat, const PlateRecuperatorConfig &cfg)
      : pre_(preheater), pre_th_(preheat_thermostat), cfg_(cfg) {}

  const char *type_name() const override { return "Пластинчатый, преднагрев"; }
  bool needs_exhaust_sensor() const override { return true; }

  FanRequest adjust(const FanRequest &base) const override {
    return frost_ladder(base, level_, cfg_.forbid_imbalance, cfg_.max_level, nullptr);
  }

  void update(const RecupContext &c, AlarmSink &alarms) override {
    // --- преднагреватель ---
    const bool th_open = pre_th_ && !pre_th_->ok();
    alarms.set(AL_PREHEAT_THERMOSTAT, th_open);
    if (pre_ && c.airflow_ok && !th_open)
      preheat_on_ = hyst_.update(c.t_exhaust, cfg_.preheat_on_below, cfg_.preheat_off_above);
    else {
      hyst_.reset();
      preheat_on_ = false;
    }
    if (pre_)
      pre_->set(preheat_on_);

    // --- лестница ---
    update_ladder_(c);
    alarms.set(AL_FROST, trip_);
    const bool exhaust_only = c.base.supply > 0 && level_ > 0 && adjust(c.base).supply == 0;
    alarms.set(AL_FROST_EXHAUST_ONLY, exhaust_only && !trip_);
    alarms.set(AL_FROST_REDUCED, level_ > 0 && !exhaust_only);
  }

  bool preheater_active() const override { return preheat_on_; }
  int frost_level() const override { return level_; }

 private:
  void update_ladder_(const RecupContext &c) {
    const uint32_t now = c.now_ms;
    if (!c.allowed || !c.in_operation) {
      if (!c.allowed) {
        level_ = 0;
        trip_ = false;
      }
      cold_since_ = warm_since_ = exhaust_only_since_ = now;
      return;
    }
    int last = 0;
    frost_ladder(c.base, 0, cfg_.forbid_imbalance, cfg_.max_level, &last);
    if (level_ > last)
      level_ = last;  // режим уменьшили — шагов стало меньше
    const bool exhaust_only = level_ > 0 && adjust(c.base).supply == 0;
    const bool cold = !std::isnan(c.t_exhaust) && c.t_exhaust < cfg_.frost_c;
    const bool warm = !std::isnan(c.t_exhaust) && c.t_exhaust > cfg_.recover_c;

    if (!exhaust_only) {
      exhaust_only_since_ = now;
      if (!cold) {
        cold_since_ = now;
      } else if (now - cold_since_ >= cfg_.step_ms) {
        cold_since_ = now;
        if (level_ < last)
          level_++;
        else
          trip_ = true;
      }
    } else if (now - exhaust_only_since_ >= cfg_.exhaust_only_max_ms) {
      trip_ = true;
    }

    if (level_ > 0 && warm) {
      if (now - warm_since_ >= cfg_.recover_ms) {
        warm_since_ = now;
        level_--;
        cold_since_ = now;
      }
    } else {
      warm_since_ = now;
    }
  }

  DigitalOut *pre_;
  SignalIn *pre_th_;
  PlateRecuperatorConfig cfg_;
  Hysteresis hyst_{};
  bool preheat_on_{false};
  int level_{0};
  bool trip_{false};
  uint32_t cold_since_{0}, warm_since_{0}, exhaust_only_since_{0};
};

}  // namespace vent

// Диагностика и пересчёт резистивных датчиков в делителе:
//   Uref ── R_top ── узел (измеряется) ── датчик ── GND

#include <cstdint>

namespace vent {

enum SensorStatus : uint8_t {
  SENSOR_OK = 0,
  SENSOR_NO_DATA = 1,       // нет свежих данных (АЦП не отвечает, I2C)
  SENSOR_OPEN = 2,          // обрыв датчика
  SENSOR_SHORT = 3,         // короткое замыкание датчика
  SENSOR_OUT_OF_RANGE = 4,  // температура вне допустимого диапазона
  SENSOR_REF_FAULT = 5,     // опорное напряжение делителя вне нормы
};

inline const char *sensor_status_text(SensorStatus s) {
  switch (s) {
    case SENSOR_OK: return "норма";
    case SENSOR_NO_DATA: return "нет данных";
    case SENSOR_OPEN: return "обрыв";
    case SENSOR_SHORT: return "КЗ";
    case SENSOR_OUT_OF_RANGE: return "вне диапазона";
    case SENSOR_REF_FAULT: return "ошибка опорного 3,3 В";
    default: return "неизвестно";
  }
}

// Классификация по отношению U/Uref: не зависит от точного значения Uref.
inline SensorStatus classify_divider(float v, float vref, float open_ratio, float short_ratio,
                                     float vref_min, float vref_max) {
  if (std::isnan(vref) || vref < vref_min || vref > vref_max)
    return SENSOR_REF_FAULT;
  if (std::isnan(v))
    return SENSOR_NO_DATA;
  const float ratio = v / vref;
  if (ratio >= open_ratio)
    return SENSOR_OPEN;
  if (ratio <= short_ratio)
    return SENSOR_SHORT;
  return SENSOR_OK;
}

// Сопротивление нижнего плеча делителя; NAN, если пересчёт невозможен.
inline float divider_low_side_resistance(float v, float vref, float r_top) {
  if (std::isnan(v) || std::isnan(vref) || !(vref > v) || v < 0.0f)
    return NAN;
  return r_top * v / (vref - v);
}

// Итоговый статус: делитель в норме, но температура не получена/вне диапазона.
inline SensorStatus final_status(SensorStatus divider, float temperature) {
  if (divider == SENSOR_OK && std::isnan(temperature))
    return SENSOR_OUT_OF_RANGE;
  return divider;
}

#pragma once
// Последовательность пуска/останова вентиляторов. Не знает, какие у установки моторы
// и заслонка: работает через FanDriver/DamperDriver. Приточного или вытяжного вентилятора
// может не быть (вытяжная/приточная установка) — тогда соответствующие шаги пропускаются.
//
// Пуск:   [заслонка открыть → ждать is_open] → вытяжка → ждать → приток → РАБОТА
//         (нагрев разрешается через heat_delay после того, как приток реально работает)
// Останов: нагрев запрещён сразу → продувка притоком → стоп притока → ждать →
//          стоп вытяжки → выбег → [заслонка закрыть]
// Только вытяжка (оттайка рекуператора): продувка → стоп притока, вытяжка работает.

#include <cstdint>

#include "damper.h"
#include "fan.h"

namespace vent {

struct FanRequest {
  uint8_t supply{0};   // 0 = стоп притока
  uint8_t exhaust{0};  // 0 = стоп вытяжки
  bool emergency_stop{false};    // немедленный стоп без продувки
  bool close_damper_now{false};  // вместе с emergency_stop: закрыть заслонку без выбега
  bool hold_purge{false};        // продувку не заканчивать (приток ещё горячий)
};

inline uint8_t clamp_level(int s, uint8_t max_level) {
  return s < 1 ? 1 : (s > max_level ? max_level : (uint8_t) s);
}

// Общий режим + смещение вытяжки. Для раздельной уставки достаточно сформировать
// FanRequest иначе — последовательность от этого не меняется.
inline FanRequest speeds_from_mode(uint8_t mode, int exhaust_offset, uint8_t max_level) {
  FanRequest r;
  if (mode == 0)
    return r;
  r.supply = clamp_level(mode, max_level);
  r.exhaust = clamp_level(mode + exhaust_offset, max_level);
  return r;
}

struct SequencerConfig {
  uint32_t exhaust_lead_ms{3000};  // вытяжка раньше притока при пуске, позже при останове
  uint32_t purge_ms{120000};
  uint32_t heat_delay_ms{10000};
  uint32_t rundown_ms{15000};      // выбег до закрытия заслонки
};

enum class FanState : uint8_t {
  STOPPED,
  DAMPER_OPENING,
  START_EXHAUST,
  RUNNING,
  PURGE,
  EXHAUST_ONLY,
  STOP_EXHAUST,
  RUNDOWN,
};

inline const char *fan_state_text(FanState s) {
  switch (s) {
    case FanState::STOPPED: return "Стоп";
    case FanState::DAMPER_OPENING: return "Открытие заслонки";
    case FanState::START_EXHAUST: return "Пуск вытяжки";
    case FanState::RUNNING: return "Работа";
    case FanState::PURGE: return "Продувка";
    case FanState::EXHAUST_ONLY: return "Только вытяжка";
    case FanState::STOP_EXHAUST: return "Останов вытяжки";
    case FanState::RUNDOWN: return "Выбег";
    default: return "?";
  }
}

class FanSequencer {
 public:
  void configure(const SequencerConfig &cfg, FanDriver *supply, FanDriver *exhaust, DamperDriver *damper) {
    cfg_ = cfg;
    supply_ = supply;
    exhaust_ = exhaust;
    damper_ = damper;
  }

  void update(uint32_t now, const FanRequest &req) {
    // Установка работает, пока нужна вытяжка (или приток, если вытяжки нет).
    bool run = exhaust_ ? req.exhaust > 0 : req.supply > 0;
    run = run && !req.emergency_stop;
    const bool supply_req = run && supply_ && req.supply > 0;

    if (req.emergency_stop) {
      if (state_ != FanState::STOPPED && state_ != FanState::RUNDOWN) {
        set_supply_(0);
        set_exhaust_(0);
        enter_(FanState::RUNDOWN, now);
      }
      if (req.close_damper_now && damper_)
        damper_->command(false);
    }

    switch (state_) {
      case FanState::STOPPED:
        if (damper_)
          damper_->command(false);
        if (run) {
          if (damper_) {
            damper_->command(true);
            enter_(FanState::DAMPER_OPENING, now);
          } else {
            start_fans_(now, req, supply_req);
          }
        }
        break;

      case FanState::DAMPER_OPENING:
        if (!run) {
          damper_->command(false);
          enter_(FanState::STOPPED, now);
        } else if (damper_->is_open()) {
          start_fans_(now, req, supply_req);
        }
        break;

      case FanState::START_EXHAUST:
        if (!run) {
          // приток ещё не запускался — нагрева не было, продувка не нужна
          set_exhaust_(0);
          enter_(FanState::RUNDOWN, now);
        } else {
          set_exhaust_(req.exhaust);
          if (exhaust_->active_level() > 0 && now - exhaust_running_since_ >= cfg_.exhaust_lead_ms) {
            if (supply_req) {
              set_supply_(req.supply);
              enter_(FanState::RUNNING, now);
            } else if (supply_) {
              enter_(FanState::EXHAUST_ONLY, now);
            } else {
              enter_(FanState::RUNNING, now);  // вытяжная установка
            }
          }
        }
        break;

      case FanState::RUNNING:
        if (supply_ && !supply_req) {
          // стоп установки или переход в «только вытяжка» — сначала продувка
          if (target_supply_ == 0)
            set_supply_(1);
          enter_(FanState::PURGE, now);
        } else if (!supply_ && !run) {
          enter_(FanState::STOP_EXHAUST, now);
        } else {
          set_supply_(req.supply);
          set_exhaust_(req.exhaust);
        }
        break;

      case FanState::PURGE:
        if (supply_req) {
          set_supply_(req.supply);
          set_exhaust_(req.exhaust);
          enter_(FanState::RUNNING, now);
        } else if (now - state_since_ >= cfg_.purge_ms && !req.hold_purge) {
          set_supply_(0);
          if (!exhaust_)
            enter_(FanState::RUNDOWN, now);
          else
            enter_(run ? FanState::EXHAUST_ONLY : FanState::STOP_EXHAUST, now);
        }
        break;

      case FanState::EXHAUST_ONLY:
        if (!run) {
          enter_(FanState::STOP_EXHAUST, now);
        } else {
          set_exhaust_(req.exhaust);
          if (supply_req) {
            set_supply_(req.supply);
            enter_(FanState::RUNNING, now);
          }
        }
        break;

      case FanState::STOP_EXHAUST:
        if (now - state_since_ >= cfg_.exhaust_lead_ms) {
          set_exhaust_(0);
          enter_(FanState::RUNDOWN, now);
        }
        break;

      case FanState::RUNDOWN:
        if (now - state_since_ >= cfg_.rundown_ms) {
          if (damper_)
            damper_->command(false);
          enter_(FanState::STOPPED, now);
        }
        break;
    }

    const bool supply_was_on = supply_level() > 0;
    const bool exhaust_was_on = exhaust_level() > 0;
    if (supply_)
      supply_->update(now);
    if (exhaust_)
      exhaust_->update(now);
    // момент фактического включения
    if (supply_level() > 0 && !supply_was_on)
      supply_running_since_ = now;
    if (exhaust_level() > 0 && !exhaust_was_on)
      exhaust_running_since_ = now;
  }

  FanState state() const { return state_; }
  const char *state_text() const { return fan_state_text(state_); }
  bool in_operation() const {
    return state_ == FanState::RUNNING || state_ == FanState::PURGE || state_ == FanState::EXHAUST_ONLY;
  }

  uint8_t supply_level() const { return supply_ ? supply_->active_level() : 0; }
  uint8_t exhaust_level() const { return exhaust_ ? exhaust_->active_level() : 0; }

  // Разрешение нагрева от вентиляции: РАБОТА, приток реально вращается без перерыва
  // не меньше heat_delay и не в паузе смены ступени, вытяжка (если есть) работает.
  bool heat_permitted(uint32_t now) const {
    return state_ == FanState::RUNNING && supply_ && supply_level() > 0 && supply_->settled() &&
           (!exhaust_ || exhaust_level() > 0) && supply_running_ms(now) >= cfg_.heat_delay_ms;
  }

  uint32_t supply_running_ms(uint32_t now) const {
    return supply_level() > 0 ? now - supply_running_since_ : 0;
  }

 private:
  void enter_(FanState s, uint32_t now) {
    state_ = s;
    state_since_ = now;
  }
  void set_supply_(uint8_t l) {
    target_supply_ = l;
    if (supply_)
      supply_->set_target(l);
  }
  void set_exhaust_(uint8_t l) {
    if (exhaust_)
      exhaust_->set_target(l);
  }
  void start_fans_(uint32_t now, const FanRequest &req, bool supply_req) {
    if (exhaust_) {
      set_exhaust_(req.exhaust);
      enter_(FanState::START_EXHAUST, now);
    } else if (supply_req) {
      set_supply_(req.supply);
      enter_(FanState::RUNNING, now);  // приточная установка
    }
  }

  SequencerConfig cfg_{};
  FanDriver *supply_{nullptr};
  FanDriver *exhaust_{nullptr};
  DamperDriver *damper_{nullptr};
  FanState state_{FanState::STOPPED};
  uint32_t state_since_{0};
  uint32_t supply_running_since_{0};
  uint32_t exhaust_running_since_{0};
  uint8_t target_supply_{0};
};

}  // namespace vent

// snprintf режет по байтам; если обрезка пришлась на середину символа UTF-8 (кириллица —
// 2 байта), убираем неполный хвост, чтобы строка оставалась корректной.
inline void utf8_fix_tail(char *buf) {
  size_t len = strlen(buf);
  size_t i = len;
  while (i > 0 && ((unsigned char) buf[i - 1] & 0xC0) == 0x80) i--;  // байты продолжения
  if (i == 0) return;
  const unsigned char lead = (unsigned char) buf[i - 1];
  const size_t need = lead >= 0xF0 ? 4 : lead >= 0xE0 ? 3 : lead >= 0xC0 ? 2 : 1;
  if (len - (i - 1) < need) buf[i - 1] = '\0';
}

// Обрезать строку UTF-8 до max_chars символов (для экрана: ширина в символах, не байтах).
inline void utf8_truncate_chars(char *buf, size_t max_chars) {
  size_t chars = 0;
  for (size_t i = 0; buf[i]; i++) {
    if (((unsigned char) buf[i] & 0xC0) != 0x80) {  // начало символа
      if (chars == max_chars) {
        buf[i] = '\0';
        return;
      }
      chars++;
    }
  }
}

    set(AL_SENSOR_OUTDOOR, has_supply && std::isnan(in.t_outdoor));
    set(AL_SENSOR_SUPPLY, has_supply && std::isnan(in.t_supply));
    set(AL_SENSOR_EXHAUST, recup_->needs_exhaust_sensor() && std::isnan(in.t_exhaust));
    set(AL_SENSOR_EXTRACT, exhaust_ != nullptr && std::isnan(in.t_extract));
    set(AL_OVERHEAT, has_supply && !std::isnan(in.t_supply) && in.t_supply > cfg_.overheat_c);
    if (has_supply && !std::isnan(in.t_outdoor)) {
      if (in.t_outdoor < cfg_.outdoor_min_c)
        outdoor_low_ = true;
      else if (in.t_outdoor > cfg_.outdoor_min_c + cfg_.outdoor_hyst_c)
        outdoor_low_ = false;
    }
    set(AL_OUTDOOR_LOW, outdoor_low_);
    set(AL_FILTER_SUPPLY, has_supply && !in.filter_supply_ok);
    set(AL_FILTER_EXHAUST, exhaust_ != nullptr && !in.filter_exhaust_ok);

    set(AL_NO_FLOW, seq_.supply_running_ms(now) >= cfg_.flow_check_ms && !in.flow_ok);
    if (seq_.supply_level() > 0 || !has_supply)
      supply_off_since_ = now;
    set(AL_FLOW_STUCK, now - supply_off_since_ >= cfg_.flow_stuck_ms && in.flow_ok);

    if (supply_) supply_->report(*this);
    if (exhaust_) exhaust_->report(*this);
    if (damper_) damper_->update(now, *this);

    const bool fire = alarms_.on(AL_FIRE);
    const bool cool_down = alarms_.any_action(AlarmAction::COOL);
    const bool stop = alarms_.any_action(AlarmAction::STOP) || (fire && cfg_.fire_purge);
    const bool start_ok = !heater_ || heater_->start_permitted();

    // --- 2. Скорости: режим (или авторежим) → рекуператор (обмерзание) → аварии ---
    uint8_t mode = in.mode;
    const bool auto_mode = in.mode == MODE_AUTO;
    if (auto_mode) {
      mode = auto_.update(now, in.co2_ppm, in.humidity, cfg_.fan_levels);
    } else {
      auto_.reset();
      if (mode > cfg_.fan_levels) mode = cfg_.fan_levels;
    }
    set(AL_CO2_SENSOR, auto_mode && auto_.sensor_missing());
    const FanRequest base = speeds_from_mode(mode, in.exhaust_offset, cfg_.fan_levels);
    FanRequest req;
    if (fire && !cfg_.fire_purge) {
      req.emergency_stop = true;
      req.close_damper_now = true;
    } else if (cool_down) {
      req.supply = cfg_.fan_levels;  // нагрев «сам по себе»: максимум воздуха, не останавливать
      req.exhaust = cfg_.fan_levels;
    } else if (!stop && mode > 0 && start_ok) {
      req = recup_->adjust(base);
    }
    req.hold_purge = has_supply && !std::isnan(in.t_supply) && in.t_supply > cfg_.purge_hold_c;
    seq_.update(now, req);

    // --- 3. Рекуператор: обмерзание и преднагрев ---
    const bool airflow_ok = seq_.heat_permitted(now) && in.flow_ok && !stop && !fire && !cool_down;
    RecupContext rc;
    rc.now_ms = now;
    rc.allowed = !stop && !fire && !cool_down && mode > 0;
    rc.in_operation = seq_.in_operation();
    rc.airflow_ok = airflow_ok;
    rc.base = base;
    rc.t_outdoor = in.t_outdoor;
    rc.t_extract = in.t_extract;
    rc.t_exhaust = in.t_exhaust;
    recup_->update(rc, *this);

    // --- 4. Нагрев ---
    if (heater_) {
      HeatContext hc;
      hc.now_ms = now;
      hc.dt_s = dt_s;
      hc.heat_allowed = in.heating_enabled && !stop && !fire && !cool_down &&
                        !alarms_.any_action(AlarmAction::BLOCK_HEATER);
      hc.airflow_ok = airflow_ok || !heater_->needs_airflow();
      hc.unit_running = seq_.in_operation();
      hc.supply_running_ms = seq_.supply_running_ms(now);
      hc.preheat_active = recup_->preheater_active();
      hc.setpoint = in.setpoint;
      hc.t_supply = in.t_supply;
      hc.t_outdoor = in.t_outdoor;
      hc.t_extract = in.t_extract;
      heater_->update(hc, *this);
    }

    // --- 5. Охлаждение ---
    if (cooler_) {
      CoolContext cc;
      cc.now_ms = now;
      cc.dt_s = dt_s;
      cc.cool_allowed = in.cooling_enabled && !in.heating_enabled && !stop && !fire && !cool_down;
      cc.airflow_ok = airflow_ok;
      cc.setpoint = in.setpoint;
      cc.t_supply = in.t_supply;
      cc.t_outdoor = in.t_outdoor;
      cc.t_extract = in.t_extract;
      cooler_->update(cc, *this);
    }

    // --- 6. Состояние ---
    status_.supply_level = seq_.supply_level();
    status_.exhaust_level = seq_.exhaust_level();
    status_.damper_open = damper_ && damper_->commanded_open();
    status_.heater_pct = heater_ ? heater_->output_pct() : 0.0f;
    status_.cooler_pct = cooler_ ? cooler_->output_pct() : 0.0f;
    status_.preheater = recup_->preheater_active();
    status_.ok = !alarms_.any_fault();
    status_.running = seq_.in_operation();
    status_.auto_mode = auto_mode;
    status_.auto_level = auto_mode ? mode : 0;
    write_status_outputs_();
    return status_;
  }

  void reset_alarms(uint32_t now, uint32_t unix_time) { alarms_.reset(now / 1000, unix_time); }

  const VentStatus &status() const { return status_; }
  const FanSequencer &fans() const { return seq_; }
  Alarms &alarms() { return alarms_; }
  const Alarms &alarms() const { return alarms_; }
  const RecuperatorDriver &recuperator() const { return *recup_; }
  int frost_level() const { return recup_->frost_level(); }
  const AutoSpeed &auto_speed() const { return auto_; }
  bool config_ok() const { return config_ok_; }
  const char *config_error() const { return config_error_; }

  // Описание профиля для интерфейса и лога.
  void profile_text(char *buf, size_t n) const {
    snprintf(buf, n, "%s; приток: %s; вытяжка: %s; нагрев: %s; рекуператор: %s; заслонка: %s; охлаждение: %s",
             unit_type_text(cfg_.unit_type), supply_ ? supply_->type_name() : "нет",
             exhaust_ ? exhaust_->type_name() : "нет", heater_ ? heater_->type_name() : "нет",
             recup_->type_name(), damper_ ? damper_->type_name() : "нет",
             cooler_ ? cooler_->type_name() : "нет");
    utf8_fix_tail(buf);
  }

  void status_text(char *buf, size_t n) const {
    const uint8_t top = alarms_.top();
    if (!config_ok_)
      snprintf(buf, n, "Авария: %s", config_error_);
    else if (top != AL_NONE && alarm_def(top).fault)
      snprintf(buf, n, "Авария: %s", alarm_def(top).text);
    else if (alarms_.on(AL_EXT_STOP))
      snprintf(buf, n, "Внешний стоп (%s)", seq_.state_text());
    else if (top != AL_NONE)
      snprintf(buf, n, "%s (%s)", seq_.state_text(), alarm_def(top).text);
    else
      snprintf(buf, n, "%s", seq_.state_text());
    utf8_fix_tail(buf);
  }

 private:
  void set(uint8_t code, bool condition) override { alarms_.set(code, condition, now_s_, unix_); }

  void write_status_outputs_() {
    if (ok_out_) ok_out_->set(status_.ok);
    if (run_out_) run_out_->set(status_.running);
  }

  // Проверка профиля: каждое найденное несоответствие — авария конфигурации, установка не пускается.
  void validate_() {
    config_ok_ = false;
    const bool need_supply = cfg_.unit_type != UnitType::EXHAUST;
    const bool need_exhaust = cfg_.unit_type != UnitType::SUPPLY;
    if (need_supply && !supply_) { config_error_ = "нет драйвера приточного вентилятора"; return; }
    if (need_exhaust && !exhaust_) { config_error_ = "нет драйвера вытяжного вентилятора"; return; }
    if (!need_supply && supply_) { config_error_ = "у вытяжной установки задан приточный вентилятор"; return; }
    if (!need_exhaust && exhaust_) { config_error_ = "у приточной установки задан вытяжной вентилятор"; return; }
    if (supply_ && !supply_->implemented()) { config_error_ = "драйвер приточного вентилятора не реализован"; return; }
    if (exhaust_ && !exhaust_->implemented()) { config_error_ = "драйвер вытяжного вентилятора не реализован"; return; }
    if (heater_ && !heater_->implemented()) { config_error_ = "драйвер нагревателя не реализован"; return; }
    if (heater_ && !supply_) { config_error_ = "нагреватель без приточного вентилятора"; return; }
    if (!recup_->implemented()) { config_error_ = "драйвер рекуператора не реализован"; return; }
    if (recup_ != &no_recup_ && cfg_.unit_type != UnitType::SUPPLY_EXHAUST) {
      config_error_ = "рекуператор возможен только у приточно-вытяжной установки";
      return;
    }
    if (damper_ && !damper_->implemented()) { config_error_ = "драйвер заслонки не реализован"; return; }
    if (cooler_ && !cooler_->implemented()) { config_error_ = "драйвер охлаждения не реализован"; return; }
    if (cooler_ && !supply_) { config_error_ = "охлаждение без приточного вентилятора"; return; }
    if ((supply_ && supply_->levels() < cfg_.fan_levels) || (exhaust_ && exhaust_->levels() < cfg_.fan_levels)) {
      config_error_ = "у вентилятора меньше ступеней, чем в режиме";
      return;
    }
    config_ok_ = true;
    config_error_ = "нет";
  }

  VentConfig cfg_{};
  FanDriver *supply_{nullptr};
  FanDriver *exhaust_{nullptr};
  HeaterDriver *heater_{nullptr};
  RecuperatorDriver *recup_{nullptr};
  DamperDriver *damper_{nullptr};
  CoolingDriver *cooler_{nullptr};
  DigitalOut *ok_out_{nullptr};
  DigitalOut *run_out_{nullptr};
  NoRecuperator no_recup_{};
  FanSequencer seq_{};
  AutoSpeed auto_{};
  Alarms alarms_{};
  VentStatus status_{};
  bool config_ok_{false};
  const char *config_error_{"не настроено"};
  uint32_t last_ms_{0};
  uint32_t now_s_{0};
  uint32_t unix_{0};
  bool outdoor_low_{false};
  uint32_t supply_off_since_{0};
};

// Экземпляр для прошивки (globals ESPHome объявляются раньше includes).
inline VentSystem &vent_system() {
  static VentSystem instance;
  return instance;
}

ПРОШИВКА
33. Шифрование API и OTA не проверено в облачной сборке (там нет доступа к реестру
    компонентов Espressif). Проверить: полная сборка `esphome compile ris400p.yaml` у себя.
34. Порог обмерзания frost_c (0 °C) и КПД рекуператора — оценки.
    → на объекте: КПД ≈ (t_supply − t_outdoor) / (t_extract − t_outdoor) при выключенных ТЭНе и
      преднагреве; лёд при выбросе +1…+2 °C во влажной квартире → поднять frost_c.
